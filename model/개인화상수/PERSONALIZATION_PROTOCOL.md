# 개인화 상수 추정 및 운영 원칙

## 목표와 시점

매일 20:00(현지시각)에 그날의 취침 시각과 다음날 기상 시각을 예측한다. 개인화 과정도 예측 시점보다 늦은 데이터는 사용하지 않는다. 새 사용자에게는 집단 기본값으로 시작하고, 누적된 과거 수면기록만으로 주기적으로 갱신한다.

## 1단계: 두 과정 모형의 개인화

항상성 수면압력 `S`는 직전 상태와 경과시간 `Δt`로 갱신한다.

```text
각성일 때: S(t+Δt) = U - {U - S(t)} exp(-Δt / τ_w)
수면일 때: S(t+Δt) = L + {S(t) - L} exp(-Δt / τ_s)
```

- `τ_w`: 개인의 수면압력이 쌓이는 시간상수
- `τ_s`: 개인의 수면압력이 해소되는 시간상수
- `U`, `L`: 상·하한
- `S(0)`: 첫날의 초기 수면압력

일주기 성분은 첫 구현에서는 다음의 해석 가능한 코사인 형태가 적합하다.

```text
C(t) = A cos{2π(t - φ) / τ_c}
z(t) = β0 + βS S(t) + βC C(t) + βxᵀx(t)
P(sleep at t) = 1 / (1 + exp(-z(t)))
```

- `A`: 일주기 진폭, `φ`: 개인 위상, `τ_c`: 개인 고유주기(기본값 약 24시간)
- `x(t)`: 20:00 이전의 심박·활동·걸음·빛 노출 등 관측 센서 특징

## 2단계: 상수 추정 방법

개인별 과거 수면 기록만 사용하여 아래 MAP(정규화된 최대우도) 문제를 푼다.

```text
θ̂ = argminθ [ -Σt {yt log pθ(t) + (1-yt) log(1-pθ(t))}
               + λΣj ((θj - μj) / σj)² ]
```

여기서 `θ = (τ_w, τ_s, U, L, S0, A, φ, τ_c, β)`이고, `μj, σj`는 문헌값 또는 학습 집단에서 얻은 평균과 변동폭이다. 마지막 항은 적은 개인 데이터만으로 비현실적인 상수가 추정되는 것을 막는다.

수면 시작·기상처럼 사건 시점만 라벨로 있는 경우에는 epoch별 수면/각성 라벨 대신 사건 오차를 최소화하는 목적함수를 쓴다.

```text
L_event = |예측 취침 - 실제 취침| + |예측 기상 - 실제 기상|
          + λΣj ((θj - μj) / σj)²
```

실무 권장 순서:

1. 첫 2주: 집단 기본 상수 + 과거 취침/기상 중앙값만 사용한다.
2. 14일 이상: `φ`, `A`, `S0`와 예측 보정계수부터 추정한다.
3. 30일 이상: `τ_w`, `τ_s`까지 정규화하여 함께 추정한다.
4. 이후: 매주 한 번, 그 시점 이전의 최근 30~90일만 사용해 재추정한다. 최종 평가 구간은 절대 재추정에 포함하지 않는다.

## 위상 φ의 간단하고 안정적인 초기 추정

최근 완료된 수면의 중간시각 `m_i`로 원형 평균을 구한다.

```text
φ_initial = 24/(2π) × arg[ Σi wi exp(i 2πm_i/24) ]  (mod 24)
```

`w_i`는 수면 품질·센서 충실도에 따른 가중치다. 이후 빛 노출 데이터가 충분하면 현재의 PCR 6변수 모델에 조도 입력을 넣어 `φ`와 `τ_c`를 상태공간 추정(확장 칼만필터/입자필터 또는 제한된 수치최적화)으로 갱신할 수 있다. 데이터가 적은 초기에 PCR의 모든 파라미터를 한꺼번에 맞추는 것은 식별이 불안정하므로 권장하지 않는다.

## 검증 규칙

- 한 예측일의 20:00 이후 센서값, 그날 밤 수면 라벨, 다음날 기상정보는 입력에 포함하지 않는다.
- 모든 스케일링·결측대치·상수 추정은 각 학습 기간 안에서만 수행한다.
- 평가는 시간순 rolling-origin 방식으로 하고, 보고 지표는 취침·기상 각각의 MAE(분), 중앙절대오차, 90% 예측구간 포함률이다.
- 개인화 전 집단모델과 개인화 후 모델을 같은 미래 기간에서 비교한다.
