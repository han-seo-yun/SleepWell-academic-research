# SleepWell 휴대폰 연결 — 0.2.0

이번 버전은 삼성헬스의 수면 기록을 휴대폰에서 읽어 Windows 앱으로 전달합니다.
Windows 10/11 x64와 Android 14 이상을 대상으로 합니다. 삼성헬스가 Health Connect에
실제로 제공한 수면 세션·단계만 사용합니다. 삼성 계정 비밀번호를 요구하지 않습니다.

## 처음 연결하기

1. PC에서 새 Windows 배포본의 압축을 **전부 풀고** `SleepWell.exe`를 실행합니다.
   이전 버전이 실행 중이면 제어창의 종료 버튼으로 먼저 종료합니다. 설치형 0.1.0을
   지우지 않고 새 압축 해제 폴더에서 0.2.0을 실행해도 같은 Windows 계정의 기록을 사용합니다.
2. 시작 정보를 저장한 뒤 화면 아래 **삼성헬스 수면 기록 연결**에서 PC 주소를 선택하고
   **연결 시작 / 새 코드**를 누릅니다. 휴대폰과 PC는 같은 개인 Wi-Fi/내부 네트워크를 사용합니다.
3. 휴대폰에 제공된 APK를 설치해 **SleepWell PC 연결**을 엽니다. 삼성헬스 설정의
   Health Connect에서 수면 기록 쓰기를 허용하고, SleepWell에는 수면 읽기 권한을 허용합니다.
4. PC의 일회용 코드를 복사하여 본인 휴대폰 앱의 연결 코드 입력란에 붙여넣습니다.
   코드는 10분 동안 한 번만 쓸 수 있습니다. 다른 사람에게 보내지 마세요.
5. 휴대폰에서 연결 후 **동기화**를 누릅니다. PC 화면을 새로고침하면 수신한 기록과
   보류 건수를 볼 수 있습니다. 수면 기록과 비교할 예측은 기존 방식대로 PC에서 미리 저장됩니다.

현재 버전은 휴대폰의 동기화 버튼으로 가져오는 방식입니다. CSV 내보내기는 필요 없지만,
휴대폰 앱이 닫힌 상태의 상시 자동 전송은 구현하지 않았습니다.
PC를 다시 실행하면 **연결 시작**을 다시 눌러야 합니다. 주소가 그대로라면 기존 휴대폰
등록은 유지됩니다. IP가 바뀌면 새 코드로 다시 연결합니다.

Windows 방화벽에서 연결 허용을 물으면 본인이 사용하는 **개인 네트워크**만 허용합니다.
조직 관리 네트워크나 게스트 Wi-Fi의 기기 간 차단은 앱에서 우회하지 않습니다.
방화벽을 끄거나 공유기 외부 포트를 열 필요가 없습니다. 이 연동 기능에는 클라우드 서버를
사용하지 않습니다.

## 가져오는 범위와 기록 해석

- 최근 최대 30일의 완료된 **삼성헬스 출처 수면**을 조회합니다. 실제 사용 가능한 기간은
  Health Connect 권한 부여 시점과 삼성헬스가 동기화한 기록에 따라 달라집니다.
- 걸음·운동·심박·카페인·일정은 이번 연동 대상이 아닙니다. 기존 입력 기능을 사용합니다.
- 수면 단계에서 첫 수면과 마지막 수면을 확인하고, 기상일별로 가장 긴 유효 수면을 주 수면으로 사용합니다.
  2시간 미만 수면, 단계 없음, 단계 사이 공백·불명확 구간은 자동 개인화에서 제외하고 보류 수를 표시합니다.
- 수면 단계는 웨어러블의 추정값입니다. 취침 시각이나 입면 지연을 직접 측정한 것으로 보지 않습니다.
  연동 기록의 `bed`/`sleep_start`에는 첫 확인된 수면 시각을 저장하며 입면 지연·주관적 개운함은 채우지 않습니다.
- 같은 날짜의 직접 입력 기록은 자동으로 덮어쓰지 않습니다. 충돌 기록은 보관하며 보류 수를 표시합니다.
  이번 화면에는 충돌 기록을 자동 병합하거나 선택 승인하는 기능이 없습니다.
- 같은 데이터를 다시 보내도 중복 기록이 늘거나 최초 수신 시각이 바뀌지 않습니다.
  수정·삭제는 반영하며, 과거 버전과 이미 저장한 예측은 유지합니다.
- 실제 수면 시각과 PC 수신 시각을 구분합니다. 늦게 들어온 기록을 과거 예측 입력에 소급 사용하지 않습니다.
  삭제·대체되어 더 이상 유효하지 않은 연동 결과는 현재 평가 집계에서 제외합니다.
- 입력 기록으로 개인화하는 구조는 유지하지만, MESA·CMI 등 연구 학습 모델을 새로 배포 모델로 통합한 변경은 아닙니다.

## 연결 관리와 저장

**수신 중지**는 네트워크 수신을 닫고, **휴대폰 등록 해제**는 기존 접근 키를 무효화합니다.
등록 해제로 이미 PC에 저장된 수면 기록까지 삭제되지는 않습니다. 새 휴대폰을 등록하면
기존 휴대폰의 접근 권한이 해제됩니다. Windows 사용자별 저장소는 한 사람의 기록에 사용하세요.

PC 기록·연결 설정은 `%LOCALAPPDATA%\SleepWell`에 저장됩니다. PC별 인증서와 비밀키가
여기에 생성되므로 이 폴더를 공개 저장소에 올리지 마세요. Android 연결 키는 기기의
Android Keystore로 암호화해 저장하고 앱 백업에서는 제외합니다.

이 배포본은 초기 시험용입니다. 실제 다른 PC와 Galaxy 휴대폰에서의 권한 화면, 방화벽,
삼성헬스 동기화는 별도로 검증해야 합니다. PC 설치파일은 코드 서명되지 않았고 Android APK는
시험용 서명이며 Google Play에 게시된 제품이 아닙니다.

## 개발·재빌드

`desktop/build_launcher.ps1`가 실행기와 `SyncCertificate.exe`를 함께 빌드합니다.
인증서 도구를 먼저 빌드한 뒤 `build_package.py prepare`를 실행해야 합니다.
Python 내장 TLS와 Windows .NET 암호화 기능을 사용하며 새 Python 패키지는 필요하지 않습니다.
TLS는 최소 1.2, 인증서는 PC에서 생성한 RSA 2048비트 자체 서명 인증서입니다. Android는
연결 코드에 담긴 SHA-256 인증서 지문을 검증합니다. 인증서 검증을 전역 해제하지 않습니다.

PC 관리 API는 계속 loopback 전용입니다. 휴대폰 수신은 선택한 RFC1918 IPv4 주소에만
바인딩하며 HTTP 접근·브라우저 Origin 요청·미인증 전송을 허용하지 않습니다.
본문 1MB, 최대 8개 동시 처리, 읽기 제한시간을 적용합니다.
일회용 코드는 5회 잘못 입력되면 폐기됩니다. 지속 접근 키는 서버에 해시만 저장합니다.
