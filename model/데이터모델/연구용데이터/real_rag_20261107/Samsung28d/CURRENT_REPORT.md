자료 출처는 실제 Samsung 측정자료로 사용자가 확인했다. 현재 분석한 28일 파일은 프로젝트 생성·재구성 스크립트 산출물과 일치하므로, 원측정값의 보존 범위와 직접 기기 내보내기 진본성은 독립적으로 확인되지 않았다고 함께 기록한다.

파일명에 `합성`이 포함된 이전 보고서는 후속 사용자 확인 전의 출처 해석을 보존한 이력이며 현재 권장 보고서가 아니다.
