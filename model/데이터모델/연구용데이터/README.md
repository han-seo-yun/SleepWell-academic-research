# SleepWell 모델용 연구 데이터

이 폴더에는 개인 자료와 이용 제한 연구 자료의 파생 데이터가 있습니다. 공개 저장소·외부 서비스에 업로드하지 마세요. 원본 `데이터셋`, `전처리데이터`, `260925`, `보조 데이터`는 수정하지 않았습니다.

## 현재 버전

- `tabular_run_20261010/`: Samsung 개인 시계열 예측과 별도 NHANES 회귀. 데이터·분할·모델·전체 실험 지표·Test 예측·학습곡선.
- `walch_run_20261010_v2/`: PSG sleep/wake, 30/60/120/300초, 16개 후보. v1 Test를 본 뒤 프로토콜 구현을 보정한 탐색적 재평가.
- `support_run_20261010_v3/`: MMASH 조건부 연구용 6,999행(성능 미평가), 보조 참고표 798행. 초기 v1은 Test 사람이 없는 hash 표본 문제 때문에 사용하지 않습니다. v2는 고정 소규모 split, v3는 동일 데이터에 provenance·유한값 검증을 추가했습니다.
- `mesa_run_20261010/`: MESA ACT 약한 라벨 2,139명, 모델용 30초 39,862,740행, Train/Validation/Test 1,525/299/315명. 16개 후보 평가 완료, 검증 선택은 30초 활동+조도 HGB입니다. 불완전 staging을 최종 데이터로 사용하지 마세요.
- `cmi_run_20261010_v2/`: 같은 밤 이벤트와 실제 cadence를 검증한 CMI 재구축본. 269명/30초 12,466,010행, Train/Validation/Test 186/39/44명. 성능은 아직 평가하지 않았습니다. 최초 `cmi_run_20261010/`는 중단된 불완전 자료이므로 사용하지 마세요.

이전 버전은 삭제·덮어쓰지 않고 보존했습니다. 각 `manifest`, `provenance`, `protocol`, split 파일로 입력과 조건을 확인하세요. 서로 다른 코호트의 사람을 연결하거나 서로 다른 목표의 성능을 하나의 accuracy로 합치지 마세요.

코드와 전체 보고서는 [RESEARCH_RESULTS_2026-10-10.md](../SleepWell-integrated/docs/RESEARCH_RESULTS_2026-10-10.md)에 있습니다. 모델 파일은 연구용이며 웹 권장 정책에 자동 적용하지 않았습니다. 자신이 생성한 신뢰할 수 있는 joblib 파일만 로드하세요.

## 검증된 실행 환경

`.venv/Scripts/python.exe`: Python 3.12.1, numpy 2.4.1, pandas 3.0.5, scipy 1.17.0, scikit-learn 1.8.0, joblib 1.5.3, threadpoolctl 3.6.0, pyarrow 26.0.0. 시스템 설치를 공유하는 연구용 venv이므로 향후 시스템 패키지가 바뀌면 동일 환경이라고 가정하지 말고 버전을 다시 확인하세요.

참가자 식별자는 비식별 연구키라도 비밀정보처럼 취급합니다. MESA의 hash token은 익명성이나 재식별 불가능성을 보장하지 않습니다. 학습에 사용한 원자료의 이용 조건은 파생 데이터에도 적용될 수 있습니다.
