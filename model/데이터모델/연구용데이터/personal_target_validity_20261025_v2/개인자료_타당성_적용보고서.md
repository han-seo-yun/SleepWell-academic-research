## 1. 현재 모델과 개인화의 의미

수리모델은 Two-Process, 데이터모델은 다음 수면 시작·종료의 행동 예측이다. 생리 시간상수 τ각성=18.2시간, τ수면=4.2시간은 고정이며 개인의 생리량으로 측정된 값이 아니다. 행동 중간시각·최근 기록의 보정과 생리상수 식별을 구분한다. 워치의 수면구간 경계, 총수면시간(TST), 권장 수면기회, 최적 필요수면, 추천의 인과효과도 서로 다른 목표다.

기존 한 참여자의 자료는 연구에 이미 사용됐다. 새 설문을 포함한 개인화 효과가 검증됐다는 뜻은 아니다. 이번 후속 평가는 과거 196밤의 고정 분할과 신규 참여자의 기존 v1 분할을 그대로 보존했다. 현재 앱의 매일 갱신 정책이나 생리상수의 정확도를 개인 자료로 검증한 것은 아니다.

## 2. 워치 모델 평가: 단순 기준선과 같은 밤 비교

입력은 `../personal_watch_survey_20261025_v1/`의 동결 결과다. 전체 251밤 중 이미 정해진 TEST 40밤(P01 30, P02 7, P03 3)만 평가했다. 기존 8개 비교군에 기존 프로젝트의 `target_validity_experiments.py` 함수를 재사용한 5개 비교군을 추가하여 총 13개 arm, 520행을 저장했다. 새 모델을 학습하거나 TEST로 모델을 선택하지 않았다.

- 최근 7회 중앙값은 **관측 7회**이며 연속 7일이 아니다.
- 새 기준선은 달력 기준 최근 7일·14일 평균, 최근 28일의 최근성 가중 평균, 정확히 같은 요일의 과거 기록, 개인 TRAIN 구간의 평균을 사용한다.
- 개인 TRAIN 평균을 집단 사전값이라고 부르지 않는다.
- 주 비교는 이번 후속 분석에서 지정한 달력 14일 평균이다. 이미 이전 TEST 결과를 본 뒤 진행한 **사후 재분석**이며 독립 사전등록 확인시험이 아니다.
- 모든 비교는 참여자 ID와 같은 밤 ID로 짝지었다. 최근 7회 중앙값도 함께 제시하여 더 약한 기준선만 선택해 개선을 과장하지 않는다.

입면·기상 MAE의 평균(분, 작을수록 좋음):

| 참여자 | TEST 밤 | 달력 14일 평균 | 최근 7회 중앙값 | CMI 융합 | MESA 융합 |
|---|---:|---:|---:|---:|---:|
| P01 | 30 | 210.00 | 160.03 | 166.83 | 161.79 |
| P02 | 7 | 140.86 | 132.25 | 132.47 | 151.12 |
| P03 | 3 | 204.77 | 216.83 | 198.08 | 229.13 |
| 참여자 동일가중 평균 | 3명 | 185.21 | 169.71 | 165.79 | 180.68 |

CMI 융합은 달력 14일 평균 대비 동일가중 MAE가 19.42분 낮지만, 최근 7회 중앙값 대비 차이는 3.92분이다. P01·P02 각각에서는 최근 7회 중앙값이 더 좋다. 평가가 3밤인 P03에도 전체 평균에서 동일한 참여자 가중치를 주므로, 집계 차이를 일반적 우월성으로 해석하지 않는다. 참여자가 3명뿐이라 신뢰구간·유의성·배포 승격을 주장하지 않았다.

### 개인 간 수준과 개인 내 변화 분리

예측 후에만 TEST 개인 평균을 제거해 centered R²를 계산했다. TEST 평균은 예측 입력이나 모델 선택에 사용하지 않았다.

| 모델 | 입면 centered R² 중앙값 | 기상 centered R² 중앙값 | 수면구간 길이 centered R² 중앙값 |
|---|---:|---:|---:|
| 최근 7회 중앙값 | -0.014 | -0.078 | -0.242 |
| CMI 융합 | 0.012 | -0.086 | -0.090 |
| MESA 융합 | 0.016 | -0.021 | 0.022 |

절대 시각 MAE가 줄었다고 개인 내 일별 변화를 잘 추적한다는 뜻은 아니다. 또한 CMI 융합의 수면구간 길이 MAE는 169.03분으로 최근 7회 중앙값의 155.71분보다 크다. 입면·기상 시각 성능과 수면시간 길이 성능을 하나로 합치지 않는다. 이 구간 길이는 PSG TST나 최적 필요수면이 아니다.

## 3. 설문·워치 연결 및 데이터 적격성

- P01 복사본 6개는 다른 참여자 이름의 작업 폴더에서도 원본과 SHA-256이 같았다. 기존 v1은 고정 export ID로 P01에 귀속하고 중복 제거했으며, 후속 분석은 그 결과를 보존한다.
- Samsung event clock은 UTC에서 명시된 offset을 한 번 적용한다. 현지 날짜 열과 설문의 `date`를 워치에 맞추려고 이동하지 않는다.
- P03 설문 14건 중 날짜상 다음 수면 연결은 7건, `savedAt < 해당 날짜 20:00`을 만족하는 연결은 0건이다.
- P04의 설문 9건 중 제때 저장된 것은 1건이나 연결되는 워치가 없다.
- 설문 효과 평가를 **모델 적합 이전에 중단**했다. 결과는 '평가 불가'이지 '효과 없음'이 아니다. 사후 입력을 예측 입력으로 사용하지 않았다.
- 설문에는 `rested`가 없으며 워치를 수동 일지로 바꾸지 않았다. 이번 후속 분석에서 심박·활동 특징을 추가 학습하지 않았다.

### 수집 계약 보완

저녁에는 예측 이전에 카페인 양·시각, 낮잠, 운동, 다음날 일정과 실제 저장시각을 수집한다. 기상 뒤에는 입면/침상 시작의 정의를 구분하고 입면 지연, 밤중 각성, 최종 기상, 개운함을 수집한다. 주간 피로·졸림은 정해진 시각과 척도 버전으로 기록한다. 늦은 응답은 보존하되 당시 이용 가능한 예측 입력으로 소급 처리하지 않는다. Windows 피로 0–10과 Android 1–5를 임의로 합치지 않는다.

이 문서는 수집·평가 계약이며 새 설문 UI나 측정항목이 배포됐다는 뜻은 아니다.

## 4. 추천·개인화 오류의 확인 및 미적용 수정안

| 확인한 문제 | 필요한 수정 | 현재 상태 |
|---|---|---|
| 웹: 입면 지연·각성 결측을 0처럼 처리해 수면량 확정 | 침상 구간을 별도 보존하고 두 값이 알려진 일지에만 추정 수면량 계산. 기존 저장된 숫자도 완전성을 재검사 | 잠금으로 미적용 |
| 웹·Android: NHANES 관측 평균이 사용자 희망 목표를 덮어씀 | 연령 범위 내 희망 목표를 권장 기준으로 유지하고 NHANES는 기술적 참고값으로 분리 | 잠금으로 미적용 |
| 서로 상쇄되는 원형자료도 확정된 위상으로 갱신 | 정규화 resultant와 위상별 적용 가중치 표시. 수치적으로 식별 불가하면 기본 위상/기상 유지 | 잠금으로 미적용 |
| Android: 침상 구간을 좋은 날의 필요수면처럼 보정 | 현재 SleepRecord에 입면 지연·각성 구분이 없어 구간 기반 목표시간 자동 조정을 보류하고 행동 기상 개인화만 유지 | 미적용 초안 보존 |

완전한 자기보고의 수면량도 추정치이지 객관적으로 측정한 생리 TST가 아니다. 제안한 resultant 1e-8은 수치적 방향 식별 경계이지 임상적 신뢰도 기준이 아니다. 미적용 패치는 정적 검토 초안이고 컴파일·회귀 검증이 완료되지 않았다. 적용 시 Android의 더 이상 쓰이지 않는 good-night 도우미/테스트와 현재 동작 안내도 함께 정리해야 한다.

PCR은 이번 범위에서 확장하지 않았다. 먼저 고정 상수 비교, 관측·대체 입력 구분, 추가 예측 이득을 검증해야 하며 모델 복잡도만으로 개인 생리량이나 추천 효과가 확인되지는 않는다.

## 재현·검증 및 제한

실행:

```text
python -B 데이터모델/연구용데이터/personal_target_validity_20261025_v2/evaluate_validity.py --workspace E:/학술제
python -B -m unittest discover -s 데이터모델/연구용데이터/personal_target_validity_20261025_v2 -p test_evaluate_validity.py -v
python -B -m unittest discover -s 기타/SleepWell-integrated/tools/model -p test_target_validity_experiments.py -v
```

이미 결과가 있는 기본 경로에서는 덮어쓰기를 거부한다. 재실행은 새 `--output` 경로를 사용한다.

- 새 연구 테스트 7개와 기존 helper 테스트 6개, 총 13개 통과.
- 원본 v1 및 helper의 실행 전후 해시 동일성, 같은 밤 짝짓기, TRAIN 평균의 TRAIN-only 재계산을 실행 중 확인했다.
- 워치 이용 가능 시각은 기상 시각이라고 가정한 후향 재현이다. 실제 과거 수신시각·수정 이력은 확인되지 않았다.
- 최적 수면 필요량, 실제 개인 생리상수, 추천의 인과효과, 새로운 참여자에 대한 일반화는 검증하지 않았다.
- 앱 소스 수정 및 Android 수정 후 테스트는 잠금 때문에 완료하지 못했다. 기존 APK/EXE와 모델 파일은 배포·교체하지 않았다.
- 연구 파일은 개인별 자료를 포함하므로 로컬 연구 폴더에만 보관하며 업로드하지 않았다.
