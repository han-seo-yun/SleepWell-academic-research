# SleepWell 0.3.0 — 사용자 앱과 연구자 소프트웨어

2026-10-24

## 실행 파일

- Android 사용자 앱: `SleepWell-User-0.3.0-debug.apk`
- Windows 연구자 소프트웨어: `Windows_연구자용_0.3.0/SleepWell.exe`
- 다른 Windows PC용 설치파일: `SleepWell-Setup-0.3.0-x64.exe`
- Windows 전체 압축본: `SleepWell-0.3.0-win-x64.zip`

파일은 모두 `E:\학술제\SleepWell_배포`에 보관합니다. 이전 0.2.0 배포본과 기존 사용자 기록은 유지합니다. ZIP은 전체를 풀어 실행해야 합니다. 기존 Windows 앱이 실행 중이면 정상 종료한 뒤 새 실행본을 여세요.

## 휴대폰 단독 사용

PC 없이 내장 CMI·MESA 데이터·수리·융합 모델을 실행합니다. 첫 2주에는 NHANES 집단 평균을 초기값으로 쓰고, 유효한 사용 후 기록이 쌓이면 최근 기록에 더 큰 비중을 두어 추천을 갱신합니다. 긴 기록 공백은 개인 기록의 비중을 낮춥니다. 연령·성별·활동량별 초기 집단을 사용하며 직업은 아직 학습된 보정 계수가 없습니다.

프로필과 수면 일기를 입력하고 주관적 회복감·피로도는 답할 때만 입력하세요. 잠든 시각은 잠자리에 누운 시각과 구분합니다. 내일의 가장 이른 일정과 준비 시간을 입력하면 기상 제약에 반영합니다. 현재 화면은 낮잠·카페인 각각 1회를 기록하며, 이 두 입력의 학습된 효과 계수는 아직 없습니다.

웨어러블 기록은 보조 지표입니다. 삼성헬스 수면 기록은 Health Connect 읽기 권한을 허용하고 화면에서 가져오기를 실행합니다. 앱이 자체 센서로 수면을 측정하거나 웨어러블에서 주관적 수면의 질을 만들어내지는 않습니다.

## 일일 백업과 PC 전달

1. Windows에서 휴대폰 수신 연결을 시작하고 일회용 코드를 생성합니다.
2. 같은 내부 Wi-Fi에 연결된 휴대폰의 PC 연결 화면에 코드를 입력합니다.
3. 사용자 앱에서 일일 자동 백업을 활성화합니다.
4. 매일 20시 실행을 운영체제에 요청하고 계산·백업합니다. 암호화한 로컬 백업과 전송 대기열을 유지하고 PC 연결이 가능할 때 재전송합니다. 수동 백업/전송도 가능합니다.
5. Windows에서 수신 건수와 최근 백업 JSON을 확인합니다. 휴대폰 스냅샷은 PC 현재 프로필과 분리 보관됩니다.

절전·강제 종료·전원 꺼짐으로 실행이 지연되거나 누락될 수 있습니다. 20:15 이후 처음 만든 예측은 정상 사전 검증으로 집계하지 않습니다. 전날 결과를 보고 과거 예측을 만들어내지 않습니다. 자동 백업은 저장된 기록에 대한 기능이며 삼성헬스의 새 기록을 백그라운드로 읽는 기능과는 다릅니다. PC가 꺼져 있어도 휴대폰 추천은 실행되며 백업은 대기합니다. PC 재실행 후 수신 연결을 켜야 전송할 수 있습니다.

## 연구 해석

현재 물리모델은 Two-Process이며 PCR은 아직 구현하지 않았습니다. CMI와 MESA에서 각각 수리 단독·데이터 단독·융합 결과를 비교합니다. 새로 탑재했다고 해서 융합이 단독 모델보다 우수하거나 수면 개선 효과가 증명된 것은 아닙니다. 모델이 예측한 불규칙한 행동 자체를 목표로 권장하지 않습니다.

직접 일지와 주관적 응답은 주 지표, 자동 웨어러블 기록은 보조 지표로 구분합니다. 수면압력 S는 측정값이 아닌 모델 상태입니다. 예측 정확도와 규칙성·회복감의 변화는 서로 다른 평가입니다.

PC 수신 백업은 외부 형식과 용량 등을 검증한 휴대폰 보고 스냅샷입니다. 내부 예측·평가 값이 PC에서 독립 재분석된 결과를 뜻하지 않습니다. Google Drive나 다른 클라우드로 자동 업로드하지 않습니다.

## 검증 범위

세부 자동 검사 결과와 파일 해시는 함께 제공한 검증 기록을 확인하세요. 실물 Galaxy의 Health Connect·배터리 제한과 다른 실물 Windows PC에서의 동작은 아직 확인하지 않았습니다. Windows 실행파일은 코드 서명 전, APK는 시험용 서명인 파일럿 배포본입니다.
