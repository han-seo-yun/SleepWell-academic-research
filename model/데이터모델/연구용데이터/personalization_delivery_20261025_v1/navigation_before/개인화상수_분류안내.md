# 개인화상수

PERSONALIZATION_PROTOCOL.md는 과거 연구 계획 문서이며 모든 수식과 갱신 단계가 현재 앱에 구현되었다는 뜻은 아닙니다. 실제 Windows 구현은 web-app/personalization.py·night_forecast.py, Android 구현은 user/UserModelEngine.kt입니다. 배포 집단 초기값은 web-app/models/population_prior.json, 생성 근거는 NHANES 보조데이터 및 next_night 연구 결과입니다. candidate_age_priors.json과 배포 population_prior.json은 구분합니다. 앱 자산을 이곳으로 옮기면 실행이 깨지므로 바로가기로 연결했습니다. 개인 사용자 상태는 앱 저장소에 유지합니다.
