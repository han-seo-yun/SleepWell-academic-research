# SleepWell 0.4.0 실행 안내

## Android 사용자 앱

`E:\학술제\어플리케이션(사용자용)\배포\SleepWell-User-0.4.0-debug.apk`를 휴대폰으로 옮겨 열고 업데이트합니다. 기존 0.3.0과 같은 서명입니다. 기록을 유지하려면 기존 앱을 삭제하지 말고 업데이트하세요. 이 APK는 시험 배포용이며 앱스토어 배포본이 아닙니다.

앱에서 예측, 권장 수면 기회, 실제 기록 변화를 구분해 확인합니다. 일지의 ‘잠든 시각’은 누운 시각과 구분한 추정 입면 시각입니다. 개운함과 피로는 각각 1–5점이며 피로는 높을수록 피곤한 상태입니다. 입력하지 않은 점수를 좋은 결과로 해석하지 않습니다.

초기 집단 평균은 참고값입니다. 기록이 쌓이면 최근 일지를 더 반영하고, 공백이 길면 개인 기록의 비중이 줄어듭니다. 추가 잔차 보정은 원래 모델과 비교하기 위해 저장되는 연구값이며 추천의 기본 정책으로 채택하지 않았습니다.

휴대폰 안에서 모델이 실행됩니다. 매일 백업 및 PC 전송 상태는 앱에서 확인하세요. PC가 꺼져 있거나 연결되지 않으면 전달이 지연될 수 있습니다. 예측 생성과 추천을 실제 화면에서 본 시각은 별도로 남깁니다. 배터리·백그라운드 제한에 따른 실기기 장기 작동 검증은 아직 수행하지 않았습니다.

## Windows 연구자용 소프트웨어

`E:\학술제\소프트웨어(연구자용)\SleepWell 연구자용 실행` 바로가기는 0.4.0을 가리킵니다. 이전 버전이 실행 중이면 종료한 뒤 이 바로가기로 다시 여세요. 다른 PC에는 같은 폴더의 `배포\SleepWell-Setup-0.4.0-x64.exe`를 전달하거나 `SleepWell-0.4.0-win-x64.zip` 전체를 압축 해제해 실행합니다.

연구 화면에서 CMI/MESA 물리·데이터·융합 모델 및 추가 보정 결과를 비교하고, 휴대폰 참여자는 별도로 선택합니다. 추천 전후 변화는 관찰 결과이며 앱의 인과적 효과를 입증하지 않습니다. 원래 예측, 최초 일지, 수정본, 노출 시각, 모델 식별자를 구분해 확인합니다.

PC의 수동 입력은 단일 참여자 시뮬레이션입니다. 이름·나이·성별을 바꾸면 다른 사람의 이력을 섞지 않도록 새 연구 기간을 시작합니다. 이전 자료는 보존됩니다. 일정·생활 선호 수정은 같은 기간을 유지합니다.
