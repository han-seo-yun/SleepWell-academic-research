# SleepWell 온라인 개인화 잔차 보정 재검증

작성일: 2026-10-25. 이 보고서는 기존 동결 `robust-v2` 모델에 추가한 온라인 잔차 보정의 탐색적 재검증이다. 기존 data/hybrid 모델은 이미 과거 수면 이력 특징을 포함하므로, 아래 비교를 ‘개인화 없음 대 개인화 있음’으로 해석하지 않는다.

## 사전 고정 정책

- 오차 부호: `실제 시각 - 동결 모델 예측 시각`.
- 현재 20시보다 먼저 결과가 확정된 과거 밤만 사용한다.
- 최근성은 입력 시각이 아니라 실제 수면 결과 시각을 기준으로 14일 반감기를 적용한다.
- 과거 14밤이 확정된 뒤 `가중치 합/(가중치 합+14)`로 최근성 가중 평균 잔차를 수축한다.
- 보정 후 기존 입면·기상 지원 범위로 투영한다.
- 14일·반감기·수축값은 문헌에서 추정한 생리 상수가 아니라 검증을 위해 사전 지정한 공학적 정책이다.
- 3밤부터 적용하는 정책은 별도 탐색 arm이며 서비스로 승격하지 않는다.

## 기존 Test 전체 행 결과

양의 개선량은 보정 후 오차가 감소했다는 뜻이다.

| 자료 | arm | Test 밤 | 보정 활성 밤 | 기존 joint MAE | 보정 joint MAE | 개선량 (95% 구간) |
|---|---|---:|---:|---:|---:|---:|
| CMI | data | 673 | 184 (27.3%) | 47.51 | 47.59 | -0.08 [-0.21, 0.05] |
| CMI | hybrid | 673 | 184 (27.3%) | 49.23 | 49.33 | -0.09 [-0.22, 0.03] |
| MESA | data | 2,175 | 0 (0.0%) | 68.11 | 68.11 | 0.00 [0.00, 0.00] |
| MESA | hybrid | 2,175 | 0 (0.0%) | 68.24 | 68.24 | 0.00 [0.00, 0.00] |
| Samsung 보조자료 | data | 30 | 16 (53.3%) | 159.83 | 161.38 | -1.55 [-5.01, 1.16] |
| Samsung 보조자료 | hybrid | 30 | 16 (53.3%) | 159.93 | 161.32 | -1.38 [-4.54, 1.18] |

기본 14밤 정책은 어느 자료에서도 개선 증거를 보이지 않았다. MESA에는 14개 이전 결과가 있는 Test 행이 없어 정책 자체를 검증할 수 없다. Samsung은 한 사람의 30밤 Test이므로 일반화 근거가 아니다. 사전 지정한 3밤 탐색 arm은 MESA data에서 0.16분의 작은 점 개선이 있었지만, CMI와 Samsung에서는 악화했고 독립 확인 자료도 없다.

## 해석과 사용 결정

이 결과는 개인화가 불가능하다는 뜻이 아니다. 현재 고정된 잔차 평균 보정이 기존 모델의 이력 특징 위에서 추가 이득을 주지 못했다는 결과다. 따라서 정책을 사용자 권장 시각에 자동 적용하지 않는다. 앱은 원래 동결 예측을 보존하고, 향후 전향적으로 저장된 예측·수동 결과가 충분히 쌓였을 때 sidecar 연구값만 병렬 저장해야 한다.

현재 Test는 이전 분석에서 이미 확인한 자료이며, `observed_at`은 실제 전향 감사 로그가 아니라 제공된 결과 가용 시각이라는 가정이 들어간다. 새로운 참여자의 미래 기록에서 계획을 동결한 확인 검증이 필요하다.

## 검증

- 기존 분할·참가자·시각 순서와 모든 목표 행을 유지했다.
- Samsung은 분할별 등록을 다시 시작했고 CMI/MESA는 참가자 단위 분리를 유지했다.
- 현재 및 미래 결과를 추가해도 현재 보정이 변하지 않는지 확인했다.
- 과거 기록 입력 순서를 섞어도 같은 결과인지 확인했다.
- 입력 파일 해시가 실행 전후 동일함을 확인했다.
- 행별 결과와 참가자 키는 연구 실행 폴더의 private parquet에만 두고, 앱에 전달하는 JSON에는 포함하지 않았다.

상세 집계는 `personalization_validation_v1.json`, 고정 계획은 `protocol.json`, 실행 확인은 `verification.json`에 있다.
