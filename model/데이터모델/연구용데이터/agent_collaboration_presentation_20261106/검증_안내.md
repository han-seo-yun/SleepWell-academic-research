# 에이전트 협업 시각화

E: SleepWell Research 상단의 `에이전트 협업` 버튼에서 확인합니다. 새 코드는 앱 재시작 후 적용됩니다.
현재 대화의 작업 ID, 연결된 기록, 8개 역할 상태, 검증된 전달 결과를 1초 주기로 읽습니다.
실선은 실제 전달 기록, 점선은 지원되는 경로입니다. 역할 번호는 순서가 아닙니다.
PNG(3840×2160), SVG, PDF 저장은 AI 호출 없이 현재 화면의 사본을 저장합니다.

## 발표 파일
- CMI_recorded_workflow: 저장된 CMI 보고서 AI 실행 기록. 보고서 관련 3개 역할 완료.
- development_recorded_workflow: 저장된 자율 설계 협업 기록. 데이터 분석·설계·수행·검수 4개 역할 완료.
서로 별도 실행이며 한 번의 8개 전체 실행으로 합치지 않았습니다.
과거에 상세 결과가 보존되지 않은 역할은 그 사실을 표시합니다.
새 보고서 실행은 검증된 역할별 결과를 agent_outputs에 보존하고 실행 해시와 대조합니다.

## 검증
- 협업 화면/데이터/그림 12개 테스트 통과
- 데스크톱 셸/협업 하네스/실험 계획 60개 테스트 통과
- 보고서 에이전트/데스크톱 대화/협업 UI 60개 테스트 통과 (UI 테스트 중복 포함)
- 현재 작업 전환, 오래된 실행 중 상태, 결과 변조, PNG 저장, 780×600/1440×900 창 크기 확인
- 실제 기록을 읽어 발표용 이미지/PDF 생성; 새 유료 AI 실행은 하지 않음
- 원자료·모델·실험·기존 보고서는 변경하지 않음
