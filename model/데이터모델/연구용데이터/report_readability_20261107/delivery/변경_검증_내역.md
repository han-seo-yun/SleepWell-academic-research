# SleepWell Research 보고서 시각화 개선

작업 위치: `E:/학술제/소프트웨어/SleepWell Academic Workbench`

사용자가 제공한 `데이터 시각화` 이미지 구성을 참고해 큰 제목, 핵심 MAE 차이, 기준 모델 비교, 공통 로그 색상표의 실제값–예측값 분포를 3840×2160 요약 그림에 배치했다. 전체 모델의 비교는 뒤의 상세 그림에서 유지했다.

## 변경
- MAE·RMSE의 모델 순서와 0 기준 축 범위를 통일했다.
- 모델별 색상, 한글 글씨 크기, 범례와 여백을 정리했다. 기준 모델은 회색으로 표시한다.
- 밀도 패널은 동일한 축·격자·로그 색상척도를 사용하며 모든 관측을 유지한다. 색 농도는 기록 수다.
- 기준 대비 오차 그림은 가중 평균과 중앙 50% 구간을 구분하고 신뢰구간이 아님을 표시한다.
- 부록 시계열은 날짜 간격을 반영하고 36시간을 넘는 간격에서는 선을 끊는다.
- 소표본에는 개별 점을 사용하고, 기준 모델이 없으면 요약 비교 그림을 생성하지 않는다.

## 검증
- 관련 회귀시험 72개, 요약 그림 전용 시험 3개 통과. Python 구문 검사 통과.
- MESA: 315명·2175밤, CMI: 44명·673밤의 완료된 실행 결과를 재사용했다.
- 원 보고서·실행 결과·에이전트 기록의 SHA-256, 비교 데이터, 첫 페이지 성능표가 변경 전과 일치한다.
- 재학습·재평가·AI 호출 없음. 저장된 확정 보고서의 해석과 지침 항목을 재사용했다.
- 각각 38쪽 PDF의 변경된 그림 페이지 4·5·6·36쪽을 렌더링해 한글, 축, 범례, 겹침, 날짜 간격을 확인했다.
- 내보내기 manifest의 생성 코드 해시가 현재 설치본 코드와 일치한다.

## 범위
이번 변경은 RAG 보고서 PDF/그림 내보내기 경로에 적용했다. 모델 실험 탭은 별도 그래프 경로이며 이번에 수정하지 않았다. 현재 실행 중인 앱에는 재시작 후 코드가 적용된다. 지침 평가와 연구자 검토 상태는 저장된 보고서 내용을 유지한다.

`verification.json`에 PDF 해시와 검증 결과가 기록되어 있다. 그림의 표시 수치는 반올림하며, MAE 차이는 반올림 전 원수치에서 계산한다.
