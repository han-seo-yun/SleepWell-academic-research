# 삼성 헬스 연결 확인

2026-11-08, A52s SM-A528N / SleepWell 오프라인 0.8.6.

## 결과

**권한과 조회 연결은 정상이며, 현재 조회 범위의 수면 기록은 0건이다. 실제 기록을 가져오는 검증은 아직 완료하지 못했다.**

- 연결 경로: 삼성 헬스 → Android 헬스 커넥트 → SleepWell 오프라인.
- 삼성 헬스의 WRITE_SLEEP 권한은 이미 허용되어 있었다.
- 새 앱의 READ_SLEEP 권한은 꺼져 있어 헬스 커넥트의 해당 앱 ‘수면’ 읽기 항목만 켰다. Android 사용자 0에서 허용 상태를 다시 확인했다.
- 사용자 설정이 완료된 앱의 ‘연결·데이터 → 지금 새 기록 확인’을 실행했다. 권한/조회 예외가 아닌 정상 조회의 0건 분기로 들어갔다. 코드상 조회 범위는 현재 시각 기준 최근 30일이며 페이지를 끝까지 읽는다.
- 앱 표시: ‘연결됨 · 주 수면 기록 기다리는 중’, ‘수면 기록을 찾지 못했어요.’
- 삼성 헬스 수면 상세 화면: 오늘 ‘데이터 없음’, 최근 7일(11/2~11/8) 수면 차트도 기록이 표시되지 않았다.
- 헬스 커넥트의 오늘(11/8) 수면 항목: ‘데이터 없음’.

삼성 헬스의 모든 과거 기록이 없다는 결론은 아니다. 현재 앱이 조회하는 최근 30일에는 기록이 반환되지 않았으며, 삼성 헬스 화면에서는 오늘과 최근 7일만 직접 확인했다. 이 근거만으로 ‘삼성 헬스 실제 기록 가져오기 완료’ 또는 ‘동기화 실패’라고 단정하지 않는다.

## 사용 시 동작

앱 진입·복귀와 사용 중 15분마다 새 기록을 확인하는 경로가 있다. 현재 기기에서는 앱 UI가 헬스 커넥트 백그라운드 읽기 기능을 지원하지 않는다고 보고하므로, 앱을 계속 닫아 둔 상태의 자동 조회를 보장하지 않는다. 삼성 헬스가 수면 기록을 헬스 커넥트로 공유한 뒤 앱을 열거나 ‘지금 새 기록 확인’을 실행해 실제 가져오기를 확인해야 한다.

수면이 끝난 뒤 공유된 기록을 읽는 방식이며 실시간 수면·각성 상태 스트리밍은 아니다. 기존 앱·삼성 헬스의 원본 수면 기록을 수정하거나 임의 기록을 넣지 않았다. 앱 소스/APK 변경도 없다.
