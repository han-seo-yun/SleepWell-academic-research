## 사용자 결정

- 평균 오차 증가의 허용 범위는 **결과를 보고 결정**한다. 임의의 1분/30초 채택 문턱을 두지 않는다.
- A52s 연결: 삼성 공식 USB 드라이버 1.9.5.0 설치와 ADB 재시작 후에도 한동안 MTP만 감지됐다. 사용자가 USB 디버깅을 다시 설정한 뒤 **SM-A528N이 ADB `device` 상태로 연결됨을 확인했다.** 별도 시험 앱으로 실기기 측정을 진행한다.
- 사용자 앱을 자동 교체하지 않는다. 정확도·실행 비용과 한계를 검토 가능한 결과로 먼저 제시한다.

## 비교 범위

- 기준 모델: 현재 서비스의 HYBRID39 TabDPT v1.3, seed 20261107, ensemble 4, 전체 Train 문맥.
- 동일 분할: `reports/equal_budget_hybrid9_20261107`의 참여자별 Train/Validation/Test. 이전 5×2 교차검증과는 다른 설계이므로 두 결과를 혼합하지 않는다.
- 경량 TabDPT: native retrieval 문맥 256/512/1024 × ensemble 1/2. Validation의 동일 코호트 가중 참여자 평균 MAE로 설정을 선택하고 잠근 뒤 Test를 평가한다.
- HGB: 위 기존 실험의 Validation에서 선택된 trial 2 모델. 새 Test 튜닝을 하지 않는다.
- 입력 특징·Train 전처리·출력 제한·시간순 잔차 보정은 기존 평가와 같다. raw 예측 성능도 별도 보고한다.
- 기존 평가자료 재사용이며 새로운 독립 검증 또는 실제 수면 개선 효과 검증으로 주장하지 않는다.

## 산출물 담당 경로

- `accuracy/`: 고정 프로토콜, 예측, 참여자 단위 성능 및 paired bootstrap.
- `mobile_export/`: TabDPT 모바일 변환과 수치 일치 검증. 정확도 비교한 Python 설정과 변환 런타임의 일치 여부를 구분한다.
- `hgb_android/`: 현재 선택 HGB의 JSON 변환, Android 독립 벤치마크 앱 및 재현 검증.

PC/GPU·x86 에뮬레이터·A52s 측정값을 명시적으로 구분한다. 모델 파일 크기, 프로세스 메모리 스냅샷, 측정된 피크 메모리도 서로 바꾸어 표현하지 않는다.

## 구현 검증에서 발견된 차이

- FAISS의 동률 이웃 선택과 모바일의 단순 거리/인덱스 정렬은 일부 중복 행에서 다른 문맥을 선택했다. 모바일은 float32 저장·float64 순차 거리 누적·행 인덱스 동률 규칙을 명시한 별도 구현으로 평가한다.
- 원래 ONNX 변환에서는 거의 일정한 열의 정규화 결과가 달라 실제 예측에도 분 단위 오차가 났다. clip/normalize/clip을 그래프 밖의 결정적 계산으로 옮긴 후보는 원본과 별도 모델로 취급한다. 32개 검증/경계 입력의 변환 일치만으로 전체 정확도를 대신하지 않는다.
- 실제 ONNX 출력의 전체 Validation/Test 평가를 준비한다. PyTorch에서 문맥 수만 줄인 결과나 검색 규칙만 바꾼 결과를 Android 모델 정확도로 표시하지 않는다.
- HGB는 전체 Test 2,848건에서 변환 전후 약 1e-12분 이하 차이, Android 24개 golden 및 4개 범위 경계 검사 통과. 모델 이진 파일 합계 456,000바이트. 초기 에뮬레이터 측정에 이어 아래 실기기 검증도 완료했다.

## 실기기와 변환 수정

- HGB A52s 검증 완료: 로드 140.733ms, 첫 요청 0.394ms, 200회 예열 후 1,000회 중앙값 0.072ms, p95 0.095ms, 50ms 표본 최대 PSS 53.2MiB. 네 모델 출력 계산 구간이며 앱 전체 UI·특징 생성은 제외한다.
- 초기 TabDPT 모바일 v1은 `thinking_embed` 64행 누락과 전체 Train 대신 선택 문맥 y 정규화 오류가 발견돼 무효 처리했다. 해당 69.317194분 Validation 및 휴대폰 자원 측정은 유효한 TabDPT 성능 비교에서 제외한다.
- 원본 `model.forward`와 독립 비교한 수정 wrapper는 같은 전처리 tensor에서 logit 최대 차이 0, attention export 재표현 후 최대 3.8147e-6을 확인했다. 전체 Train y 정규화로 수정한 v2 그래프·golden·전체 정확도·실기기 실행을 다시 검증한다.
- 배포 앱/서버는 유지한다. 사용자가 결과를 검토해 모델을 결정하기 전에는 교체하지 않는다.
