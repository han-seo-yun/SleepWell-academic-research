# HGB HYBRID39 Android 경량화·실행 검증

2026-11-08. 기존 제품 앱과 서버를 변경하지 않고 별도 벤치마크 앱에서 검증했다. Android 에뮬레이터와 Galaxy A52s 실기기에서 같은 포터블 HGB 계산을 확인했다.

## 산출물과 정확성

- 고정된 참여자 분리 실험에서 Validation으로 선택된 HGB trial 2를 그대로 사용했다. CMI와 MESA 모두 Train만으로 적합된 모델이며 Test로 설정을 고르지 않았다.
- 원시 HYBRID39 입력에 기존 Train 전처리를 적용한 뒤 HGB를 계산한다. CMI는 37개, MESA는 31개 변환 특징을 사용한다.
- Test 전체 2,848행(CMI 673, MESA 2,175)에서 Python 원본과 모바일 포터블 계산을 비교했다. 전처리 최대 절대오차는 0, 원시 예측 최대 절대오차는 CMI `1.0232e-12`분, MESA `1.1369e-12`분이었다.
- 고정 실험의 저장된 Test 예측과 sklearn 원본은 오차 0이었다. 범위 제한 후 저장된 Test 예측과 포터블 계산의 최대 절대오차도 각각 `1.0232e-12`, `1.1369e-12`분이었다.
- Android에서 24개 golden 행의 원시 예측과 범위 제한 예측은 모두 오차 0으로 일치했다. 입면·기상 극단값 4개 경계 사례도 통과했다.

## 경량화

| 항목 | CMI | MESA | 합계 |
|---|---:|---:|---:|
| 검토용 JSON | 850,195 B | 846,154 B | 1,696,349 B |
| APK용 무손실 이진 모델 | 228,060 B | 227,940 B | 456,000 B |

이진 형식은 모든 수치를 IEEE-754 binary64로 저장한다. 양자화하지 않았으므로 이 변환 자체로 예측 정밀도를 낮추지 않는다.

## Android 에뮬레이터 측정

측정 범위는 서로 다른 CMI·MESA 39개 특징 벡터에서 두 코호트의 입면·기상 네 출력을 계산하고 범위를 제한하는 모델 구간이다. 수면일지에서 특징을 만드는 과정과 개인화·권장 정책은 포함하지 않았다. 200회 예열 후 1,000회 측정했으며 출력 합계를 volatile sink에 누적해 계산 생략을 막았다.

| 실행 | 세션 로드 | warm 중앙값 | warm p95 | 로드 후 PSS | 요청 사이 최대 PSS |
|---|---:|---:|---:|---:|---:|
| 1 | 401.0 ms | 2.753 ms | 9.323 ms | 29,698 KB | 42,103 KB |
| 2 | 441.3 ms | 1.952 ms | 5.723 ms | 28,998 KB | 43,328 KB |
| 3 | 603.4 ms | 1.770 ms | 5.857 ms | 30,638 KB | 42,013 KB |

기기는 Android 37 `sdk_gphone64_x86_64` 에뮬레이터다. PSS는 요청 사이에 표본화했으므로 요청 내부의 순간 최고 메모리는 아니다. 이 수치는 A52s 성능으로 환산할 수 없다.

## Galaxy A52s 실기기 측정

기기는 Samsung SM-A528N, Android 14(API 34), arm64-v8a, 물리 메모리 약 5.24 GiB다. 측정 범위는 위 에뮬레이터와 같은 모델 전용 구간이며, 첫 요청은 예열 전에 따로 측정했다. 이후 200회 예열 후 1,000회의 warm 지연을 측정했다.

| 세션 로드 | 첫 요청 | warm 중앙값 | warm p95 | 50 ms 표본 최대 PSS |
|---:|---:|---:|---:|---:|
| 140.733 ms | 0.394 ms | 0.072 ms | 0.095 ms | 54,489 KB (53.2 MiB) |

- 24개 golden 행의 원시·범위 제한 예측은 모두 오차 0이었고 상태는 `pass`였다.
- 별도의 초기 콜드 실행 두 회에서 세션 로드는 255.505 ms와 130.583 ms였고, 세 번째 재실행은 134.160 ms였다. 페이지 캐시와 기기 상태가 달라 콜드 값에 변동이 있다.
- 50 ms 간격 PSS는 순간 최고값의 근사치다. 단일 HGB 요청이 0.1 ms보다 짧아 요청 내부의 아주 짧은 메모리 피크를 완전히 포착한다는 뜻은 아니다.
- 전체 벤치마크 시작 전 배터리 48%, AP 31.1°C, 피부 29.2°C, Android thermal status 0이었다.

## 빌드·오프라인 확인

- `assembleDebug`와 `lintDebug`가 성공했다. Lint 오류는 0이며 벤치마크 전용 앱의 아이콘·번역 및 도구 버전 경고 4건만 있다.
- APK 권한 덤프에는 패키지명만 있고 권한이 없다. `INTERNET` 권한도 없다.
- 원래 에뮬레이터 APK 크기는 2,859,593바이트, SHA-256은 `fea9926346309918bac4c0f0477f87e9328e8b1b02373b65a99fa2702a9538ff`다.
- 첫 요청과 50 ms PSS 표본을 추가한 A52s APK 크기는 2,861,665바이트, SHA-256은 `960b10dc6bdddb1ce8af06dbde105bf63492a246bf0471f63954686655e05713`다. 두 APK 모두 디버그용이며 모델 외 벤치마크 코드와 golden fixture가 포함된다.

## 남은 검증

A52s에서 HGB의 정확한 실행과 자원 사용은 확인했다. 다만 이 결과는 모델 전용 구간이며 수면일지→39개 특징 생성, 개인화, 권장 시각 생성, UI 전체 지연을 포함하지 않는다. 수정된 TabDPT 모바일 그래프가 완성되기 전에는 두 후보의 최종 비교나 제품 앱 교체를 결정하면 안 된다.
