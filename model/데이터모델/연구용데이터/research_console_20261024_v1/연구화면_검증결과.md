# SleepWell 연구 진단 화면 0.3.1

Windows 시작 화면을 연구 모델 비교로 전환했다. PC 프로필 없이 사용한다.
수동 입력/추천은 선택적인 시뮬레이션으로 남겼다. Android APK는 변경하지 않았다.

## 확인 가능한 것

- CMI/MESA 각각 물리·데이터·융합 모델의 입면/기상/평균/간격 MAE, 인원·밤 수, 그래프.
- 모델 파일 해시와 버전, 학습 집단·전처리·선택 규칙, Two-Process 계산식과 고정 상수.
- NHANES 추천 초기값과 CMI/MESA 학습분할의 연구 예측 초기값 구분.
- 휴대폰 기기·참여자·날짜별 여섯 모델 출력, S/C/임계값, 개인화 비중·날짜별 이력, 입력 특징.
- 정확한 모델 해시/버전/특징 계약을 확인한 자료만 저장 특징→출력을 PC에서 재계산해 비교.
  허용 오차 1e-6분. 물리 분기는 저장된 물리 예측 특징의 출력 일관성만 검사한다.
- 전체 특징 생성, S/C 궤적, 예측의 사전 고정 여부, 실제 예측 정확도는 이 산술 검사로 검증하지 않는다.

## 현재 연구 결과: 참여자별 동일 가중 평균 MAE

| 집단 | 물리 | 데이터 | 융합 | 평가 자료 |
|---|---:|---:|---:|---|
| CMI | 66.25분 | 47.51분 | 49.23분 | 44명 · 673밤 |
| MESA | 90.35분 | 68.11분 | 68.24분 | 315명 · 2,175밤 |

융합이 데이터 단독보다 개선되지 않았다. 기존 Validation/Test를 재사용한 분석으로,
새로운 외부 검증 또는 SleepWell의 수면 개선 효과로 주장하지 않는다.
수면압력은 직접 측정값이 아니며 시간상수18.2/4.2시간, 일주기 진폭0.15는 고정이다.
연구 예측의 n/(n+14) 가중치와 추천의 최근성 감쇠 가중치는 서로 다른 계약이다.

## 검증

- 웹 테스트136건 실행:135 통과, 선택형 원본 sklearn parity1 제외.
- 별도 원본 sklearn parity 실행6건 모두 통과:CMI4,627행/MESA14,761행 원본 대비1e-9분 이내.
- Windows 호스트/패키지/휴대폰 동기화 테스트23건 모두 통과.
- 프로필 없는 시작, 코호트 전환, 빈 휴대폰 목록, 합성 스냅샷 표시,
  여섯 모델 표와 특징→출력 일치 표시를 실제 숨김 브라우저로 확인.
- 패키지701파일 해시 검증, 설치기 패키지 검사와 격리 DB 실행/종료 검사 통과.

화면 캡처의 휴대폰 참여자는 검사 전용 합성 자료다. 실제 사용자 DB나 배포본에 포함하지 않았다.
실제 휴대폰에서 이번 화면으로 새 백업을 전송하는 실기기 검사는 수행하지 않았다.
최근365개 참여자-일 스냅샷 조회 한도가 표시된다. 기존 배포/원자료는 유지했다.
Google Drive 업로드는 하지 않았다.

실행: E:\학술제\소프트웨어(연구자용)\배포\Windows_연구자용_0.3.1\SleepWell.exe
