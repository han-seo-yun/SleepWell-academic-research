# 연구자용 진단 화면 작업

- 기존 모델·상수·훈련 결과는 변경하지 않는다. 원본 및 배포 모델 해시 일치를 확인했다.
- 프로필 입력 없이 CMI/MESA의 모델별 수치, 산출물 근거와 검증 한계를 보여준다.
- 휴대폰 참여자는 기기/참여자 식별자별로 분리하며 날짜별 수신 결과를 검사한다. 백업을 PC 일지에 합치지 않는다.
- 측정값, 계산값, 고정 상수, 개인화 추정값과 독립 검증 범위를 구분한다.
- 기존 융합 테스트 baseline: 13건 실행, 12 통과, 선택적 sklearn 검증 1 skip.
- 새 진단 회귀검사, 전체 앱 검사, Windows 패키지 검사와 실행 확인 후 0.3.1로 별도 배포한다.
