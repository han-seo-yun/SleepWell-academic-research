# SleepWell 연구자용 macOS 사용 안내

버전 0.6.6 · macOS 11 이상 · 연구자용 로컬 프로토타입

Windows 연구자용과 같은 연구 화면, 연구 분석실, CMI·MESA 융합 모델 추론 코드를 사용합니다. 앱 소스는 Windows 패키징과 같은 허용 목록·변환 규칙으로 통합 저장소에서 가져오며, 실행기·Python 런타임·패키지만 macOS용입니다. 연구 해석 기준은 함께 들어 있는 `docs/연구자 융합모델 안내.md`를 먼저 확인하세요. PCR은 탑재하지 않았습니다.

## 어떤 파일을 받나요

| Mac 종류 | 파일 |
|---|---|
| Apple 실리콘 (M1·M2·M3·M4 등) | `SleepWell-0.6.6-mac-arm64.dmg` |
| Intel Mac | `SleepWell-0.6.6-mac-x86_64.dmg` |

확인 방법: 화면 왼쪽 위  메뉴 → **이 Mac에 관하여**에서 ‘칩’이 Apple M…이면 arm64, ‘프로세서’가 Intel이면 x86_64입니다.

## 설치

1. DMG를 열고 **SleepWell.app**을 옆의 **Applications(응용 프로그램)** 폴더로 끌어 놓습니다.
2. 외장 디스크(T9 등)나 DMG 안에서 바로 실행하지 마세요. macOS가 외장 exFAT 디스크의 실행을 막을 수 있습니다. 반드시 응용 프로그램 폴더로 복사한 뒤 실행합니다.

Python을 따로 설치하지 않아도 됩니다. 앱 안에 CPython 3.14.7과 numpy·matplotlib 등 고정 버전 패키지가 들어 있으며, Mac에 설치된 다른 Python의 영향을 받지 않습니다.

## 처음 열 때 (보안 확인)

이 앱은 Apple 개발자 인증서로 서명·공증되지 않았습니다(ad-hoc 서명). 인터넷·메신저로 받은 경우 처음 실행 시 macOS가 막습니다.

- **macOS 14 이하**: 응용 프로그램 폴더에서 SleepWell을 **Control-클릭(우클릭) → 열기 → 열기**.
- **macOS 15 이상**: 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 ‘SleepWell이 차단되었습니다’ 옆 **그래도 열기**를 누르고 암호를 입력합니다.

한 번 허용하면 다음부터는 그냥 열립니다. Gatekeeper 등 보안 기능을 끄는 방식은 안내하지 않습니다. 기관 관리 Mac에서 허용되지 않으면 Developer ID 서명·공증 배포본이 필요합니다.

## 0.6.0 화면 구성

왼쪽 메뉴가 하나의 앱으로 정리되었습니다.

- **대시보드**: 참여자 수, 관측된 밤, 오늘 20시 사전 예측, 확인이 필요한 항목(기록 공백·늦은 입력·동기화 지연)과 참여자별 최근 14일 기록 띠.
- **참여자**: PC·휴대폰 참여자 목록과 상세(SRI·IS/IV, 입력 시점, 관측 수면 액토그램). 표준 5열 CSV 받기와 **연구 분석실에서 분석**(그 참여자 기록을 분석실에 자동으로 불러옴).
- **연구 분석실**: 별도 창 없이 앱 안에서 열립니다. 메뉴 위 링크로 새 창에서도 열 수 있습니다.
- **기기 연결·API**: 휴대폰 연결, 내보내기, 로컬 읽기 API(`/api/v1`, OpenAPI 문서) 안내.
- 왼쪽 아래 **라이트·시스템·다크**로 화면 테마를 고릅니다.

대시보드와 참여자 화면의 수치는 관측 기록의 기술 요약이며 모델 정확도·임상 판단·추천 효과가 아닙니다.

## 현재 모델·관측 계약

- 운영 추천은 첫 유효 일지부터 최근성 개인화를 계산하지만 근거가 부족·노후·불규칙하면 위상과 목표 수면시간은 가입 시 값을 유지합니다. 14일은 대기기간이 아니라 최근성 반감기와 초기값 수축 강도입니다.
- 명시적 입면 또는 입면잠복기가 없으면 취침을 입면으로 대체하지 않습니다. 입면잠복기·중간각성 구성요소가 불완전한 수면시간은 결측으로 유지합니다.
- 사전 예측은 등록 다음 20시부터 30일 calibration과 30일 held-out 기간을 고정합니다. calibration 적격 결과가 20건 이상일 때만 `recent_adaptive`의 입면·기상 결합 90% 예측구간을 동결하며, 이는 추천 효과나 개인 생리 상수의 구간이 아닙니다.
- 최초 추천 후보는 예상 입면 2시간 전과 20시 중 이른 시점, 이후 갱신은 20~23시입니다. 신선한 각성 관측이 없으면 갱신하지 않으며 기록 부재를 각성으로 간주하지 않습니다.
- 센서 Process S 비교는 연속된 5분 관측과 검증 보정된 확률을 명시적으로 넣은 연구 실행에 한정됩니다. 일반 실행은 센서 관측을 자동 생성하지 않고, 공백·미보정·불확실성 초과 시 일지 S로 돌아갑니다.
- `/api/v1`은 참여자별 읽기 전용 스냅샷·표준 CSV·OpenAPI를 제공합니다. SRI·IS·IV·입력 완결성은 관측 데이터 기술통계이지 정확도·임상 판단·추천 효과가 아닙니다.

## 실행과 종료

SleepWell을 열면 작은 **제어창**이 뜨고, 연구 엔진이 준비되면 기본 브라우저에서 연구 화면이 열립니다. 처음 실행은 그래프 글꼴 캐시를 만드느라 최대 1분 정도 걸릴 수 있습니다. 주소는 이 Mac 내부의 임시 포트(`127.0.0.1`)를 사용합니다.

- **화면 열기**: 연구 화면을 다시 엽니다.
- **연구 분석실**: 실제·가상 입력 비교와 Matplotlib 진단 그림 화면을 엽니다.
- **기록 폴더 열기**: 이 Mac의 기록 저장 위치를 Finder로 엽니다.
- 제어창의 빨간 닫기 버튼: 창만 숨기고 실행은 유지합니다. 메뉴 막대 오른쪽의 달(🌙) 아이콘이나 Dock 아이콘으로 다시 열 수 있습니다.
- **종료** 또는 ⌘Q: SleepWell이 시작한 로컬 연구 엔진을 정상 종료합니다. 다른 Python 프로그램은 건드리지 않습니다.

브라우저 탭을 닫아도 앱은 계속 실행됩니다. 20시 사전 예측을 자동 저장하려면 **Mac이 깨어 있고 SleepWell이 실행 중**이어야 합니다. 잠자기·종료 중에는 저장하지 않으며, 로그인 시 자동 시작은 설정하지 않았습니다.

## 휴대폰 연결

Windows판과 같은 방식입니다(`docs/휴대폰 연결 안내.md`). 연결을 시작하면 macOS가 **로컬 네트워크 접근** 또는 **수신 연결 허용** 여부를 물을 수 있습니다. 같은 내부 네트워크의 휴대폰이 접속하려면 허용해야 합니다. 연결용 인증서는 macOS 기본 `openssl`로 기록 폴더 안에 만들며, 키체인이나 시스템 신뢰 저장소는 바꾸지 않습니다.

## 기록·백업

개인 기록: `~/Library/Application Support/SleepWell/sleepwell.sqlite3`
(Finder에서 ⌘⇧G를 누르고 `~/Library/Application Support/SleepWell` 입력, 또는 제어창의 **기록 폴더 열기**)

배포 파일에는 사용자 기록, Samsung 개인 모델, MESA·CMI 원자료가 들어 있지 않습니다. 각 macOS 사용자는 자기 기록으로 시작합니다. 같은 폴더의 `desktop-host.log`에는 시작 실패 같은 운영 오류만 남고 기록 내용은 남지 않습니다.

Windows와 Mac 사이에서 기록을 옮길 때는 양쪽 SleepWell을 완전히 종료한 뒤 `sleepwell.sqlite3`를 따로 백업해 옮기세요(Windows 위치: `%LOCALAPPDATA%\SleepWell`). 대상에 이미 기록이 있으면 먼저 그 DB를 백업해야 합니다. 자동 병합·JSON 복원 기능은 없습니다.

삭제: SleepWell을 종료하고 응용 프로그램 폴더에서 SleepWell.app을 휴지통으로 옮깁니다. 기록 폴더는 별도로 보존됩니다.

## 기능 범위와 검증

기능 범위와 해석상 주의는 Windows판과 같습니다. 0.5.0에서 추가된 관측 데이터 진단(수면 규칙성·데이터 완결성·액토그램)과 배치 실행은 `docs/연구 분석실 안내.txt`를 보세요. 수면 일정 추천, 일정·낮잠·카페인 입력, 개인화, 사전 예측 저장과 실제 결과 비교를 제공합니다. 카페인 효과 계수, 개인별 생리 시간상수 추정, 수면 개선 효과는 검증 완료된 기능이 아닙니다. 평가 MAE는 입면·최종 기상 시각 예측 오차이며 수면의 질 점수가 아닙니다. 합성 예제는 실제 정확도 근거가 아닙니다.

macOS판은 macOS 14(Apple 실리콘)에서 빌드·검증했습니다. Intel판은 같은 Mac의 Rosetta에서 실행 검증했으며, 실제 Intel Mac과 다른 macOS 버전에서는 아직 검증하지 않았습니다. 수치 계산 라이브러리가 Windows와 같은 버전이어도 플랫폼별 부동소수점 차이로 마지막 자릿수가 다를 수 있습니다.
