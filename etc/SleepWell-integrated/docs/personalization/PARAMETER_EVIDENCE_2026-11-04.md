# 시간상수·개인화 설정값의 근거와 적용 범위 — 2026-11-04

후속 검토(2026-11-05): 초기값 약 40% 잔존의 의미와 개인 비중을 높이는 네 대안을 [장기 개인화 검토](PERSONALIZATION_GROWTH_REVIEW_2026-11-05.md)에 정리했다. 이어 [베이지안 갱신·일부 계수 적합](BAYESIAN_PERSONALIZATION_REVIEW_2026-11-05.md)도 실제 비교했다. 두 비교 모두 CMI·MESA 잔차 평가와 한 사람의 장기 행동 시각 보조 분석에서 변경을 지지할 개선이 확인되지 않아 현재식을 유지한다. 아래는 11월 4일 검토 기록이다.

검토 대상은 현재 Windows 웹앱과 Academic Workbench에 포함된 동일 계산 코드다. **τw=18.2 h, τs=4.2 h를 유지한다.** 문헌에서 수치를 추적할 수 있는 고정 구현 기본값이며, 사용자의 일지나 EEG로 추정한 개인 생리값은 아니다. 개인화 설정값의 변경 판단은 아래 비교 보고서의 실제 결과를 따른다. 논문의 출판 연도, 수학적 모형의 타당성, 이 앱의 성능 검증을 구분했다.

## 2. 18.2와 4.2의 수치 출처

직접 수치를 확인한 자료는 Van Dongen, Bender & Dinges (2012)의 **2.3 Mathematical modeling**이다. 수면·각성 변화율을 각각 `r_s=1/4.2`, `r_w=1/18.2`로 두면서 Borbély & Achermann (1999)을 인용한다. 따라서 근거 연결은 **현재 코드 → 2012년 논문의 명시된 수치 → 그 논문이 인용한 1999년 문헌**으로 기록한다. 2012년 연구는 건강한 성인 9명의 반복 수면박탈에서 PVT 수행을 분석했으며, 일반 사용자의 다음 밤 예측이나 추천 효능을 검증한 연구는 아니다. [Van Dongen et al., 2012, 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC3260461/), [DOI](https://doi.org/10.1016/j.aap.2011.09.018), [Borbély & Achermann, 1999](https://doi.org/10.1177/074873099129000894).

현재 정규화된 상태 S의 계산은 다음과 같다. 시간 t의 단위는 시간이다.

\[
S_{wake}(t)=1-(1-S_0)e^{-t/18.2},\qquad
S_{sleep}(t)=S_0e^{-t/4.2}.
\]

Daan, Beersma & Borbély (1984)는 EEG 기반 수면 회복과 일주기 조절을 결합한 구조의 근거다. 이번 검토에서 그 논문 원문에 두 숫자가 직접 제시되는지까지 확인하지 않았으므로, **18.2/4.2의 직접 확인 출처로 1984년 논문만 달지 않는다.** 올바른 페이지는 R161–R178이다. [Daan et al., 1984](https://doi.org/10.1152/ajpregu.1984.246.2.R161).

개인차가 없다는 뜻도 아니다. Rusterholz et al. (2010)은 건강한 젊은 남성 8명의 EEG 서파활동을 이용해 개인별 상승·감쇠 상수의 차이를 보고했다. 해당 모형은 하한 점근값도 추정한다. 양의 하한을 둔 개인 적합에서 상승 14.1–26.4 h, 감쇠 1.2–2.9 h가 보고되지만, **점근값과 관측 모형이 다른 수치를 현재 0–1 모형에 그대로 대입할 수 없다.** 일지 기반 취침·기상 정보만으로 생리 τ와 행동·일정·일주기 효과를 분리했다고 주장하지 않는다. [Rusterholz et al., 2010, 원문 및 Tables 1, 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC2849788/).

## 4. 단순한 개인화식의 수학적 근거와 한계

아래 혼합식은 실수형 가중 평균과 잔차 평균을 설명한다. 추천 엔진의 d는 기상 이후 경과일이며, 잔차 보정의 d는 `outcome_at` 이후 경과일이다. 보고 도착시각은 잔차의 이용 가능 여부를 판정한다. 추천 엔진의 원형 시각 평균·가중 중앙값은 별도 계산이다.

\[
w_i=2^{-d_i/h},\quad M=\sum_i w_i,\quad
\alpha=\frac{M}{M+\lambda},\quad
\theta=(1-\alpha)\theta_0+\alpha\bar{x}_w.
\]

일반 실수값의 가중 평균 갱신은 다음 목적함수의 해와 같다. 이는 **현재 구현을 설명하기 위한 수학적 유도**이며, 인용 논문이 이 앱의 식과 숫자를 직접 제안했다는 뜻은 아니다.

\[
\arg\min_\theta\left[\sum_iw_i(x_i-\theta)^2+\lambda(\theta-\theta_0)^2\right]
=\frac{\sum_iw_ix_i+\lambda\theta_0}{M+\lambda}.
\]

기하급수적으로 최근 관측에 큰 가중치를 주는 원리는 [Roberts (1959)](https://doi.org/10.1080/00401706.1959.10489860), 제곱 페널티를 통한 수축의 일반 원리는 [Hoerl & Kennard (1970)](https://doi.org/10.1080/00401706.1970.10488634)와 연결된다. 두 논문 모두 **h=14일 또는 λ=14를 수면자료에서 산출하지 않았다.** 원형 시각 평균·최단 시각차 혼합과 목표 수면시간의 가중 중앙값에는 위 실수 제곱손실 유도를 그대로 적용하지 않는다. 실제 분산을 추정하지 않았으므로 경험적 베이즈 추정이나 검증된 신뢰도로 명명하지 않는다.

h는 날짜 단위의 기억 길이이고 λ는 최대 가중치 1인 관측에 상대적인 사전 강도다. 같은 숫자 14가 쓰여도 역할은 다르다. λ를 고정한 채 h를 바꾸면 기억 길이뿐 아니라 누적량 M과 개인화 비중도 바뀐다.

매일 1개씩 age=0,1,…인 이상적인 기록에서는 h=14일일 때 M의 극한이 약 20.70, α의 극한이 약 0.597이다. **기록이 오래 쌓여도 이 경로는 약 40%의 초기값 영향을 유지한다.** 이는 설계의 결과로 설명해야 하며, 성능 근거 없이 오류로 단정하거나 제거하지 않는다. 첫 기록 가중치가 1이면 α=1/15이고, ±180분 잔차가 주는 최초 보정은 최대 ±12분이다. 실제 시각 간격이 있으면 더 작아진다. 반면 `night_core`의 n/(n+14)는 n이 늘면 1로 접근한다.

## 5. 현재값과 대안의 비교 및 변경 판단

실행 가능한 비교 도구는 [compare_personalization_settings.py](../../../research_workbench_academic/scripts/compare_personalization_settings.py), 실제 자료 결과와 판정은 [비교 보고서](../../../reports/personalization_settings_20261104/REPORT.md)에 기록한다. 입력·예측·모델·코드 해시와 실행 전 확정한 후보/판정 규칙을 보존한다.

**실행 결과: 현재 h=14일, λ=14, 최소 이력=1, 잔차 제한=±180분, 보정 제한=±60분을 유지한다.** 11개 대안 모두 변경 기준을 통과하지 못했다. Validation에서 고른 최소 이력 3개 대안의 평균 이득은 0.131분, 재사용 Test에서는 0.087분이었다(참여자 군집 부트스트랩 95% CI −0.022~0.201분). 동일 코호트의 두 예측군에 같은 참여자 재표본을 사용했다. 현재값의 최적성이 입증됐다는 뜻은 아니다. 평가 구현을 검토·수정한 내역도 [방법 감사 기록](../../../reports/personalization_settings_20261104/METHOD_AUDIT.md)에 공개했다.

Test의 참여자 균등 joint MAE는 다음과 같다. 두 군은 같은 참여자·밤을 사용한다.

| 코호트·예측군 | 참여자 / 밤 | 현재 설정(분) | 최소 이력 3개(분) |
|---|---:|---:|---:|
| CMI data | 44 / 673 | 47.777 | 47.662 |
| CMI hybrid | 44 / 673 | 49.474 | 49.296 |
| MESA data | 315 / 2,175 | 67.981 | 67.956 |
| MESA hybrid | 315 / 2,175 | 68.130 | 68.100 |

비교 범위는 **동일한 동결 `gradual_v1` 예측에 덧붙이는 잔차 보정**이다. h=7/14/28일, λ=7/14/28, 최소 이력=1/3/7/14, 잔차 제한=90/180/360분, 보정 제한=30/60/90분을 한 항목씩 변경하고, 보정 없음도 기준으로 확인한다. 모든 조합의 최적값 탐색은 아니다.

기존 CMI/MESA 참여자 분할을 보존하고, 각 예측 시점 전에 실제로 이용 가능했던 이전 결과만 사용한다. 같은 참여자의 현재·미래 결과가 과거 보정으로 들어가지 않게 하며, 참여자별 평균 오차를 먼저 계산해 긴 기록이 있는 사람이 결과를 지배하지 않도록 한다. 후보 하나를 Validation에서만 고정한 뒤 재사용 Test에서 평가한다. 두 코호트·두 예측군을 동시에 확인하며, 참여자 군집 부트스트랩과 다중 비교를 고려한 구간을 보고한다. 변경 기준의 1분은 이번 비교의 공학적 최소 이득 기준이며 임상적 중요도 기준이 아니다.

이 자료는 **이미 사용한 후향적 보류 자료**다. 이번 후보 비교에서 Test로 선택하지 않는 것과, 과거에 전혀 노출되지 않은 새 Test인 것은 다르다. 예측 개선 판정이 나더라도 독립 외부·전향 검증이나 수면 개선 효과를 입증한 것으로 쓰지 않는다.

추천용 `engine.parameters`에는 개운함·피로도·일정·추천 준수에 관한 목표가 포함된다. 이번 CMI/MESA 시각 예측 자료로 추천의 h·λ나 목표 수면시간 제한을 최적화할 수 없으므로 해당 값은 유지한다. `night_core`의 n/(n+14) 특징과 이미 학습된 모델 파일도 이번 잔차 비교의 변경 대상이 아니다.

## 6. 재현과 유지보수

2026-11-04 코드 변경은 세 계산 모듈의 **주석·문헌 연결**이며, 실행 AST의 변경 전후 동일성을 확인한다. Academic Workbench의 vendor 사본을 같은 바이트로 맞추고 현재 `SOURCE_MANIFEST.json`만 갱신한다. 과거 평가 JSON, 완료된 run, 배포 ZIP, 모델 가중치의 해시는 당시 증거로 보존한다. 새 평가에는 새 출처 해시를 기록한다.

문헌 검토는 2026-11-04 기준의 목적별 확인이며 체계적 문헌고찰 전체를 수행했다는 주장은 하지 않는다. 수치의 직접 출처·최근 적용·현재 앱으로의 일반화 한계를 구분하는 검토 절차에 `scientific-critical-thinking` skill을 사용했다. 방법론 출처에 대한 기존 고지는 [NOTICE_SOURCES.md](../NOTICE_SOURCES.md)에 유지하며, 해당 방법론 자료를 수면학 근거로 사용하지 않는다.
