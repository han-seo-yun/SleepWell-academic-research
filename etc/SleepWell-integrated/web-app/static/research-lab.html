연동된 연구 검토 공간

본 앱 기록은 읽기 전용 스냅샷으로 가져와 분석합니다.

가져온 자료나 모델 파일은 변경하지 않으며, 평가 결과는 이 세션에서만 계산합니다.

01

실험 입력

입력 근거
비교할 코호트 모델
실제 데이터 형식
실제 입력 규칙
  • 열은 participant_id, cutoff, sleep_start, sleep_end, observed_at 다섯 개입니다.
  • 시간은 UTC 오프셋을 포함해야 하며 cutoff는 해당 야간의 20:00입니다.
  • 정답이 없는 예측 전용 행은 sleep_start, sleep_end, observed_at을 모두 비웁니다.
  • 참가자 ID는 가명이어야 하며 파일 경로, URL, 메모, 자격 증명을 넣지 마세요.

세션을 불러온 뒤 평가할 수 있습니다.

03

모델 비교 결과

현재 입력에 연결된 결과가 없습니다.

현재 예측은 첫 유효 기록부터 개인화 값을 점진 반영합니다. 기존 동결 가중치에 추론 개인화 정책을 변경했으므로 별도 검증이 필요하며, 기존 저장 Test 성능은 이전 정책의 결과입니다.

동일 야간 성능 비교

모든 모델에 정답이 있는 같은 야간만 비교하고 참가자를 동일 가중합니다. n과 참가자 수를 오차와 함께 해석하세요.

논문용 모델 진단 그림

현재 실행에서 Python Matplotlib로 생성했습니다. 화면 PNG와 함께 벡터 그림·원자료·재현 정보를 묶어 받을 수 있습니다.

관측 데이터 진단

입력된 관측 수면 자체의 규칙성과 완결성입니다. 모델 예측과 독립적으로 계산합니다.

기술통계

수면 규칙성

SRI는 24시간 간격 같은 분의 수면·각성 일치도(−100~100), IS·IV는 시간별 수면 비율의 일간 안정성·일내 변동입니다. 주 수면만 입력되므로 낮잠은 반영되지 않습니다.

데이터 완결성·입력 시점

‘다음 20시 전 입력’은 관측 결과가 다음 날 예측 이력에 들어갈 수 있었던 밤입니다. 늦게 입력된 밤은 다음 예측에 쓰이지 않습니다.

계산 가정

    04

    재현·진단 상세

    핵심 성능 그림과 중복되거나 모델 내부 확인에만 필요한 표는 아래에 접어 두었습니다.

    실행 모델·표본·artifact 해시
    공통 야간 성능의 전체 진단 지표

    핵심 표에서 생략한 구간 MAE·RMSE를 포함합니다. 동일한 공통 야간과 참가자 동일 가중 조건입니다.

    공통 야간 제한 전 모델별 가용 지표

    모델마다 평가 가능한 야간 구성이 다를 수 있어 핵심 모델 순위 비교에는 사용하지 않습니다.

    모델 내부 개인화 궤적 그림

    성능 순위와 직접 같은 질문을 답하지 않는 모델 내부 진단 그림입니다.

    로컬 모델 버전·해시

    재현성 점검에 필요한 모델 상태입니다. 성능 결과는 위의 동일 야간 비교에서 확인합니다.

    모델 상태를 확인하고 있습니다.

    보조 맥락 자료 품질·가용성

    수신 건수와 분석 가능한 야간을 구분합니다. 기록이 존재한다는 사실만으로 효과나 연관성을 뜻하지 않습니다.

    개인화 입력·특징·상태

    모델 계산에 전달된 robust feature와 night_core 상태입니다. 새로 적합한 생리 상수가 아닙니다.
