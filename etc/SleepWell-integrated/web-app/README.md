## 일정 입력·최근성 개인화·사전 저장 검증 (2026-10-20)

계획 밤별로 다음날 근무·수업·첫 일정과 준비시간, 이미 완료된 낮잠, 이미 섭취한 카페인을 입력할 수 있습니다. 이른 다음날 일정은 기상 제약을 앞당기고, 근무·수업의 시작·종료가 모두 있으면 점유 구간과 겹치지 않는 연속 수면 가능 구간을 찾습니다. 완료된 낮잠은 수면압력 계산에 반영하지만 카페인은 당시 입력에만 보존하며, 개인별 카페인 효과 계수나 섭취 권고량은 없습니다.

이 절을 처음 작성했을 때의 14일 전환 규칙은 `legacy14` 비교 계약으로 보존합니다. 현재 운영 개인화는 첫 유효 기록부터 `gradual_v1`로 계산하되 위의 보수적 근거 플래그를 적용합니다. 누적 기록은 보존하고 기상 후 경과시간에 14일 반감기를 적용하며, 개인화 비중은 `유효 가중 기록 수/(유효 가중 기록 수+14)`입니다. 결측 가능한 항목은 값이 있는 기록만으로 별도 가중치를 계산합니다.

서버가 실행 중이면 매일 20:00(Asia/Seoul)에 그 시점까지 확인된 입력으로 다음 밤 예측을 한 번 고정합니다. 20:00~20:15 생성만 주 평가에 포함하고, 꺼져 있던 과거 밤을 소급 생성하지 않습니다. 고정 비교군은 `profile_baseline`, `recent_adaptive`, `context_candidate` 세 개이며 주 모델은 `recent_adaptive`입니다. 첫 실제 결과를 주 평가에 쓰고 같은 수면의 수정본은 별도 집계합니다. 날짜를 수정해도 이미 연결된 예측과 결과의 정체성을 임의로 바꾸지 않습니다. 자세한 계약은 [사전 저장 예측·앱 변경 문서](../docs/PROSPECTIVE_APP_2026-10-20.md)를 참고하세요.

이 구조는 앞으로 모이는 자료로 오차를 측정하기 위한 것입니다. 세 비교군의 성능 향상, 권장 시각의 수면 개선 효과, 카페인의 인과 효과는 아직 입증되지 않았습니다. 예측 구간은 주수면 시작부터 최종 기상까지이며 총수면시간(TST)이 아닙니다. 과거의 고정 테스트 개수는 현재 검증값으로 사용하지 않으며, 최신 실행 결과는 문서 상단의 현재 기준을 따릅니다.

## 사용 흐름

1. 별명, 나이, 성별(선택), 생활 유형, 하루 활동시간(선택), 평소 수면·활동 평균과 목표 기상을 입력합니다.
2. 기존 Samsung 자료가 본인 자료라면 **기존 본인 자료 연결**을 체크합니다. 학생 집단 평균으로 취급하지 않습니다.
3. 첫날부터 권장 취침·기상 시각, 이유, 수면압력 곡선을 제공합니다.
4. 다음날 완료된 수면과 개운함·피로도, 기상일의 걸음·운동을 기록합니다. 미측정은 빈칸으로 둡니다.
5. 첫 유효 일지부터 최근성 개인화 상태를 갱신합니다. 근거가 부족·노후·불규칙하면 위상과 수면 목표는 가입 시 값을 유지하며, 과거 아카이브를 불러온 날짜는 신규 관측일로 세지 않습니다.
6. 계획 밤의 다음날 일정·준비시간과 완료된 낮잠·카페인 섭취를 입력합니다. 일정은 수면 가능 구간에, 낮잠은 수면압력에 반영되며 카페인은 검증용 입력으로만 저장됩니다.
7. 이후 기록할 때마다 누적 기록을 보존하면서 최근 기록과 공백을 반영해 개인화값과 추천을 갱신합니다. 같은 기상일의 수정은 최신 관측 한 번만 현재 개인화에 반영합니다.
8. 서버가 20시에 실행 중이면 다음 밤 예측을 미리 고정하고, 실제 기록이 들어오면 최초 결과와 수정 결과를 나누어 비교합니다.
9. `전체 기록 내려받기`로 프로필, 기록, 일정 버전, 사전 저장 예측과 평가 이력을 JSON으로 백업합니다.

## 구현된 개인화

- 처음 2주: `population_prior.json`에서 연령대·성별·활동 수준이 맞고 30명 이상인 NHANES 집단의 관측 수면시간 평균으로 시작합니다. 세부 집단이 부족하면 같은 연령대·성별의 활동 전체→같은 연령대의 성별·활동 전체→전체 평균 순서로 넓히며, 자료가 없거나 지원 연령 밖이면 가입 시 입력한 대체값을 사용합니다.
- 직업은 저장하지만 현재 NHANES 사전값 선택이나 학습 효과에 사용하지 않습니다. 직업별 효과가 검증된 것처럼 표시하지 않습니다.
- 초기 수면 위상은 집단의 취침시각을 가져오지 않고 사용자가 입력한 평소 취침·기상으로 계산합니다. 자료 연결 시 과거 본인 활동 평균과 최근 30회 수면 위상을 참고할 수 있습니다.
- 과거 위상은 현재 자기보고 75%, 과거 원형평균 25%로 초기화합니다. 이 가중치는 아직 검증 전 운영 규칙입니다.
- 개인화 전환 후: 유효 관측은 누적 보존하되 기상 후 경과일에 14일 반감기를 적용합니다. 초기값과 섞는 비중은 `유효 가중 기록 수/(유효 가중 기록 수+14)`이며, 긴 기록 공백은 유효 기록 수와 개인화 비중을 낮춥니다.
- 일주기 위상은 최근성 가중 원형평균으로 계산합니다. 입면 여유·걸음·운동은 해당 값이 있는 날만 사용해 항목별 최근성 가중 평균과 항목별 수축 비중을 계산합니다.
- 개운함 4점 이상이고 피로도 3점 이하(또는 미응답)인 날이 5일 이상이면 최근성 가중 수면시간 중앙값을 목표에 반영합니다. 초기 집단값 또는 대체 초기값 대비 ±30분으로 제한합니다.
- τ각성=18.2h, τ수면=4.2h, 일주기 진폭=0.15는 아직 고정입니다. 이 값들을 14일로 추정했다고 주장하지 않습니다.
- 활동·운동 평균은 생활 기준 및 이후 연구 입력으로 저장하며, 수면 필요량으로 직접 환산하지 않습니다.

## 추천 목표 및 연구 모델 연결

목표는 **수면 개선을 위한 일정 제안**입니다. 다음날 기상 제약과 수면 기회 확보를 우선하고, 그 주변 30분 후보에서 Two-Process S/C와 규칙성을 비교합니다. 입력된 근무·수업 점유 구간을 피하고 완료된 낮잠을 수면압력에 반영합니다. 최근 수면 부족에 따른 수면 기회 확대(최대 30분)는 검증 전 정책입니다.

다음날 예측은 권장 정책과 분리되어 있습니다. 20:00 이전 기록으로 수리물리·데이터·하이브리드 후보를 비교하고 검증 구간에서 선택한 승자를 보조 예상 시각에 사용합니다. 이 예상 행동을 권장 시각의 정답이나 추천 효과의 증거로 사용하지 않습니다. `--forecast-model PATH`로 연결하는 기존 경량 JSON 경로도 입력 계약과 적용 범위를 만족할 때만 사용합니다.

현재 시간대는 Asia/Seoul 고정입니다. 교대근무·다상수면·수면장애 치료용 일정 최적화는 구현하지 않았습니다. 직접 입력 수면은 입면/각성 미입력 시 침대 체류시간을 사용하므로 수면시간을 과대 추정할 수 있습니다.

## 저장과 운영

로컬 1인 프로필입니다. 인터넷 회원가입·다중 사용자 인증·서버 업로드는 없습니다. 서버는 `127.0.0.1`에만 바인딩되어 다른 기기의 iPhone Safari에서 이 주소로 연결할 수 없습니다. iPhone 센서 자동 연동은 별도 `ios-app` 프로젝트에 있습니다. 웹앱 기록과 iOS 앱 저장소는 현재 자동 동기화되지 않습니다.

프로필을 다른 사람으로 바꾸면 기존 기록과 섞이므로 **동일인의 설정 수정**으로만 사용하세요. 추천은 생성 시각, 정책 버전, 입력 해시, 당시 설정·상수·일정 입력 버전을 보존합니다. 사전 예측은 20시 입력 스냅샷과 세 비교군 출력을 변경하지 않고 저장합니다. 최초 실제 결과를 주 평가에 사용하고 이후 수정은 별도 집계하며, 준수 오차를 효과 지표와 구분합니다.

전체 백업 JSON을 정기적으로 다른 안전한 위치에 보관하세요. DB 파일은 Git에서 제외되고 원본 연구 파일은 수정하지 않습니다. JSON 복원 UI, 웹앱 자체의 HealthKit 자동 가져오기, 추천 효과의 통계 검정은 후속 작업입니다. 고정 모니터링의 90% 구간은 다음날 행동 시각 예측 오차용이며 추천 효과나 개인 생리 상수의 구간이 아닙니다.

## 실행 / 검증

Windows PowerShell:

```powershell
cd web-app
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
.\.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -q
```

macOS/Linux:

```bash
cd web-app
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
.venv/bin/python -m unittest discover -s tests -v
```

무상태 연구 분석실은 선택 그래프 의존성을 설치한 뒤 별도로 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-research-lab.txt
.\.venv\Scripts\python.exe research_lab_server.py
.\.venv\Scripts\python.exe research_lab_cli.py --help
```

추천 기본 경로는 표준 라이브러리로 실행 가능합니다. pandas/pyarrow/scikit-learn/lightgbm은 기존 개인자료·연구 모델 연결에 필요합니다. 의존성 또는 원본 자료가 없으면 자체 입력 추천만 사용합니다.
