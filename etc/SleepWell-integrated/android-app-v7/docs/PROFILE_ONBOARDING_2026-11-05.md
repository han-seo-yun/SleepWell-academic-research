# 최초 기본정보 입력 — 2026-11-05

## 사용자 동작

- 앱 시작 시 완료된 프로필이 없으면 기본정보 입력 화면을 먼저 표시한다. 입력을 저장하기 전에는 분석 화면과 자동 건강 데이터 조회를 시작하지 않는다.
- 성별(여성/남성/응답 안 함), 연령대(18–29/30–44/45–59/60–80), 직업군(학생/직장인/기타)을 명시적으로 선택한다.
- 희망 수면시간, 평소 취침·기상, 하루 활동량도 확인하고 저장한다.
- 희망 수면시간은 시간·분 입력란에서 분 단위로 직접 지정한다. 기존 모델 계약인 7~9시간 범위를 검사하며, 최초 입력과 내 정보 수정에 같은 방식을 사용한다. [추가 검증](DATA33_ACCUMULATION_2026-11-05.md).
- 저장이 성공해야 분석 화면으로 이동한다. 다음 실행부터 저장한 정보를 사용하며, `내 정보 → 수정`에서 같은 편집기로 변경하고 다시 계산한다.
- 기존 파일의 유효한 값은 보존한다. 직업군이나 완료 표시가 없는 예전 프로필은 최초 입력 화면에서 확인한다. 새 사용자에게 성별·연령대·직업군을 임의로 선택하지 않는다.
- 정보는 앱 전용 로컬 파일에 저장하며 외부 전송을 추가하지 않았다.
