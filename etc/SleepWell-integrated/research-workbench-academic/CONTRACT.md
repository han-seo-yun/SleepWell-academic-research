# Research Workbench implementation contract

Native Windows Tkinter desktop, pandas / scikit-learn 1.8 / Matplotlib, Python 3.12. No browser or web server. Root owns GUI and subprocess queue. Modules use ordinary dictionaries and JSON-safe results. All data row identifiers are original zero-based positional integers; reset_index(drop=True) on import.

## Shared interfaces

`researchbench.engine.make_split_plan(df, config) -> dict`: config keys task (`classification`/`regression`), target, features, split (`random`/`group`/`time`), group, time, test_size (0.2), folds (3), seed (42). Return `id`, `train_rows`, `test_rows`, `folds` list of `{train: [...], valid: [...]}`, `strategy`, `seed`. Plan independent of selected features; optional `stratify_target` overrides target, None disables stratification. Target missingness filtered within run; plan reuse in two-task projects.

`run_experiment(df, config, plan, progress=None, cancelled=None) -> result`: progress(event dict), cancelled() -> bool. config keys `id`, `name`, `task`, `target`, `features`, `model` (`dummy`/`linear`/`forest`/`mlp`), `params` dict, `imputer` (`median`/`mean`/`constant`), `encoding` (`onehot`/`ordinal`), `scaling` (`standard`/`robust`/`none`), `positive_class`, `threshold` (0.5), `average` (`macro`/`weighted`), `class_weight` (None/`balanced`), `target_unit`, `target_transform` (`none`/`log1p`/`standard`), `bin_edges` optional ordered finite cuts, `bin_labels` optional, `bin_rationale`, `device` (`cpu`), `primary_metric`, `max_seconds`, `data_hash`. No test predictions by default. `evaluate_final(df, config, plan, progress=None, cancelled=None)` evaluates the locked chosen config on test rows, distinct result phase.

Result keys `id`, `name`, `task`, `config`, `split_id`, `data_hash`, `phase` (`validation`/`final_test`), `status` (`completed`), `folds`: list `{fold, metrics: {metric: number or None}, reasons:{metric: reason_code}, n_train,n_valid, train_rows, valid_rows}`, `summary`: `{metric:{mean,std,n}}`, `predictions`: list `{row_id,fold,y_true,y_pred,probabilities:[...]}` (regression no probabilities), `classes` original class labels, `history`: list `{fold,epoch,train_loss,valid_loss}`, `duration`, `versions`, `device`. Metrics keys `roc_auc`, `average_precision`, `accuracy`, `balanced_accuracy`, `recall`, `specificity`, `precision`, `f1`, `mae`, `mse`, `rmse`, `r2`. Error codes English stable identifiers; translated at presentation. Progress keys `stage`, `fold`, `total_folds`, `epoch`, `total_epochs`, optional metrics/loss. Engine must validate configs and resource caps and avoid fitting preprocessing outside train.

`researchbench.data.load_data(path, sheet_name=0) -> DataFrame`; `data_profile(df) -> dict` with `rows`, `columns` count, `features` list of `{name,dtype,missing,missing_pct,unique,constant}`, `duplicates`, `warnings` list of dict `{code,column,...}`; `fingerprint(df) -> str`.

`researchbench.storage.Project.create(path, df, name, source_path='') -> Project`; `Project.open(path) -> Project`; `.df`, `.path` Path, `.state` dict (`name`, `data_hash`, `source_path`, `roles`, `tasks`, `baselines` per task, `graph_settings`, `ui`, `splits`), `.save()`, `.save_experiment(record)`, `.experiments() -> list`, `.close()`. Immutable experiment records except lifecycle updates for same id; completed config/result must never silently overwritten. Open marks running/queued/cancelling as interrupted. Persist metadata, results, snapshot atomically. Never pickle untrusted input.

`researchbench.plotting.make_figure(kind, *, df=None, results=None, metric='roc_auc', lang='ko', options=None, target=None, feature=None, baseline_id=None) -> matplotlib.figure.Figure`. Kinds `correlation`, `missing`, `histogram`, `box`, `target`, `scatter`, `comparison`, `delta`, `roc`, `pr`, `confusion`, `predicted`, `residuals`, `learning`. options title/xlabel/ylabel/annotation (None automatic; '' hides), font_size, width, height, dpi, legend, color, corr_method, scope. Current language only affects labels. `export_figure(fig,path,dpi=300)`; `comparison_table(results,baseline_id,lang='ko') -> DataFrame`; `export_tables(results,path,baseline_id=None,lang='ko')` csv/xlsx.

Root owns `researchbench/i18n.py` with `tr(key,lang='ko',**kwargs)`, language JSON resources; plotting agent owns separate plot resources or passes own translated labels, no dependency on root UI catalog. Root owns `queueing.py`, `recommendations.py`, `app.py`, `__main__.py`. Engine agent owns `engine.py`, `metrics.py`, engine tests. Data/plot agent owns `data.py`, `storage.py`, `plotting.py`, tests for these and plot locale resources. Validation/packaging agent owns scripts, requirements, README, sample generation, integration tests, examples, and optional smoke tests; do not modify others' modules, report defects upward.

First complete classification and regression baseline + feature removal with identical split, save/reopen, figures/tables. Then multiclass/dual workflow and neural epoch tracking/recommendations. No nested CV in v1: holdout mandatory and final one-time project task test lock. Do not present SD as CI. Threshold fixed before run; tuning by validation comparisons, never test. Sample only preview/EDA visibly; training uses eligible full data. Single-worker serial queue initial concurrency cap = 1. Optional GPU only if implemented/tested otherwise explicitly document CPU-only scope.

## Validation

Meaningful unittest coverage for train-only imputation, holdout isolation, group/time invariants, same split feature comparisons, target inversion, positive-class mapping/threshold, unavailable metrics, storage immutable outputs/recovery/hash drift, language output and custom labels, multiprocessing completion/cancellation and Tk responsiveness. Windows real Tk smoke with both languages and exported PNG/PDF/SVG. Pin tested installed package versions in requirements; installer creates private .venv and shortcut, launch scripts. Keep original workspace untouched.
