# SleepWell 작업 흐름 단순화 — 2026-11-05

목표: 주 화면을 데이터 품질, 모델 실험·시각화, 근거 기반 보고서의 세 단계로 줄인다.
기존 원자료, 모델, 완료 실행, 보고서는 변경하지 않는다.

## 보존 동작과 사전 검사

- 불변 입력 스냅샷·해시 검사, 별도 프로세스 실행·중단, 실제 지표·그림·PDF 생성.
- 기존 academic_app / knowledge_ui / academic_jobs 검사 22개 통과.
- 새 회귀 검사는 세 메뉴, 기존 페이지 상태 전환, 실행과 결과 연결, 품질 문제 표시,
  선택한 실행에 대한 보고서 근거 연결과 취소를 다룬다.

## 범위와 순서

1. 메뉴 10개와 작업공간 선택기를 세 메뉴로 축소. 전향 수집, 후향 검증 설계,
   재학습·교차검증·외부 검증, 일반 데이터 도구는 기본 작업 흐름에서 제거.
2. 데이터 품질을 행·참여자·결측·중복·시간 오류와 열별 표로 표시. 원자료를 자동 수정하지 않음.
3. 실행 설정, 실행/중단, 진행 상태, 그래프, 성능 표를 한 화면에 연결.
   기존 자료의 탐색 실험이며 임상 또는 독립 검증 완료로 표현하지 않음.
4. 선택 실행 → 공식 문서 로컬 검색 → 지표와 인용이 연결된 PDF를 한 경로로 제공.
   기준 gradual_v1 보고서는 별도 출처 선택. 생성형 LLM 사용 여부를 사실대로 표시.
5. 관련 회귀 검사, 실제 실행·PDF 생성, 네이티브 화면 크기와 한국어 가독성 확인.

## 정리 판단

- 중복 UI 경로/불필요한 기본 메뉴: 제거할 UI 복잡성.
- 별도 프로세스·해시 검증·오류 표시는 근거 있는 실패 방어로 유지.
- 새 UI는 실행 실패/근거 누락을 과거 성공 결과나 gradual_v1 결과로 바꾸지 않는다.
- 과거 데이터 형식과 테스트용 개별 패널 API는 보존하되 기본 화면에서 노출하지 않는다.
- 새로운 의존성, 모델 교체, 원자료 정리, 외부 전송은 도입하지 않는다.

담당: 메인 에이전트(화면·통합), 독립 에이전트(품질 계산, 보고서 흐름).
완료 후 별도 읽기 전용 검토로 실제 선택 결과의 출처와 미완료 검증 표현을 확인한다.
