# AI 보고서 구현·검증 기록 (2026-11-05)

바탕 화면 SleepWell Academic Workbench 바로가기의 대상인 이 설치 폴더에 반영했다. 현재 실행 중인 두 앱 창은 종료하지 않았다. 새 코드는 다음 실행부터 로드된다.

## 변경 파일

- `researchbench/ai_connections.py`: API 제공자, 자격 증명 설정, 모델 조회, 제한된 요청과 오류 처리.
- `researchbench/chatgpt_auth.py`: 공식 ChatGPT SIWC 로그인, 서명·계정 검증, 토큰 갱신·로그아웃.
- `researchbench/report_agents.py`: 역할별 에이전트, 지침 검색 도구, 실행 한도·감사 기록, 보고서 결합 검사.
- `researchbench/report_ai_ui.py`, `knowledge_ui.py`: 기존 세 화면 안의 연결 설정, 실행·중단, 미리보기와 PDF 출력.
- `researchbench/reporting.py`, `comparison_reporting.py`, `report_export.py`: 변경 불가능한 기본 수치와 AI 해석을 별도 버전으로 결합하고 PDF 저장 시 다시 검증.
- 새 연결·인증·에이전트·화면 회귀시험, `scripts/verify_ai_report.py`, 사용법 문서.

추가 패키지를 설치하지 않았다. 기존 모델 가중치·원자료·완료 실행을 변경하지 않았다. 생성 경로를 기존 보고서 화면에 통합하고 별도 에이전트 관리 페이지는 만들지 않았다.

## 확인한 결과

- 관련 회귀시험 **143/143 통과**.
- 마지막 섹션/실행 기록 검증 보완 후 에이전트·화면 시험 **15/15 통과**.
- Windows 토큰 저장 보완까지 반영한 최종 인증·제공자·에이전트·화면 시험 **63/63 통과**.
- 전체 검사 **489개 중 488개 통과, 1개 환경 오류**. 기존 장기 기록 분석의 Parquet 입력 시험에 필요한 `pyarrow`/`fastparquet`가 설치되어 있지 않다. 이 작업에서 해당 분석 코드나 의존성을 변경하지 않았다.
- Python 전체 모듈 문법 검사와 새 모듈 import 통과. 별도 lint/typecheck 도구는 저장소 환경에 구성·설치되어 있지 않다.
- 실제 저장된 CMI Train 실행에서 `cmi.data`, `cmi.hybrid`, `baseline.recent7`을 선택해 공통 52밤·3명의 화면 지표와 PDF 지표가 일치함을 확인.
- 공식 TRIPOD+AI·PROBAST+AI 문헌 검색, 세 역할 모의 호출, 보고서 검사, 한국어 PDF **12쪽·Matplotlib 그림 7종**을 확인하고 모든 페이지를 렌더링해 검수.
- API 키를 프로젝트에 저장하지 않는 경로, 선택 스냅샷 고정, 화면 이동 후 작업 완료, 취소, 변조 차단, 로그인/갱신/로그아웃은 모의 네트워크·키링으로 검사.
- 실제 Windows 자격 증명 저장소에 합성 API 키를 저장·조회·삭제했다. 긴 OAuth 묶음의 WinVault 항목 크기 제한을 발견해 청크 저장으로 보완했고, 무작위 시험 계정의 합성 12KB 묶음 저장·복원·삭제를 확인했다. 기존 사용자 자격 증명에는 접근하지 않았다.
- 실제 Windows RSA 서명 검증에서 생성한 정상 서명을 수용하고 변경된 입력은 거부했다. 인증이 필요 없는 OpenAI 공개 OIDC 설정의 고정 엔드포인트 일치와 JWKS 키 4개도 실제 조회했다.

검증 산출물은 `../reports/ai_report_agents_20261105/verified/`에 있다. `VERIFICATION.json`은 입력·PDF·구현 코드 해시, 선택 모델, 지표, 실행 기록과 검사 결과를 보관한다.

## 남은 실제 연결 검증

실제 사용자의 ChatGPT 로그인·플랜 자격, API 키의 모델 접근 권한, 실제 AI 생성 품질과 청구는 확인하지 않았다. 시험 PDF의 수치는 저장된 실험에서 왔지만 AI 문장은 **모의·시험 실행**으로 표시했다. 새 전향·외부 검증이나 PROBAST+AI 최종 평가를 수행한 것으로 표시하지 않는다.

ChatGPT 구독에서는 제공자가 출력 토큰·API식 USD 한도를 지원하지 않아 해당 설정을 비활성화했다. 자체 호출·시간·응답 크기 한도를 사용한다. 사용자 지정 호환 API의 DNS 사전 검사에는 재해석 시점 차이의 제한이 있으므로 네트워크 샌드박스로 간주하지 않는다. 공식 API와 사용자 지정 주소의 차이는 [연결 문서](AI_CONNECTIONS.md)에 기록했다.
