# SleepWell AI 보고서 사용법

기본 메뉴는 **데이터 품질 → 모델 실험·시각화 → RAG 보고서**입니다. 기존 완료 실행·모델 가중치·원자료는 그대로 사용합니다.

## 연결과 출력

1. 모델 실험 화면에서 완료 실행, 비교 모델, 예측 대상, 집계 방식과 허용오차를 선택합니다.
2. RAG 보고서 화면에서 비교 설정을 확인하고 **AI 연결 설정**을 엽니다.
3. OpenAI 또는 Anthropic API를 선택해 키를 붙여넣고 **설정 저장**을 누릅니다. 또는 ChatGPT 구독을 선택하고 **ChatGPT로 로그인**을 눌러 공식 브라우저 동의를 완료합니다. 다른 ChatGPT 계정은 `다른 ChatGPT 계정으로 새 연결`을 선택합니다.
4. **모델 목록**에서 사용 가능한 모델을 골라 설정을 저장합니다. API 목록에는 보고서 생성에 적합하지 않은 모델도 있을 수 있으므로 텍스트 대화 모델을 선택합니다. **연결 확인**은 모델 조회만 하며 보고서를 생성하지 않습니다.
5. **AI 근거 분석·보고서 작성**을 누릅니다. 성능 분석 → 지침 검토 → 보고서 작성 → 수치·출처 검사가 순서대로 실행됩니다.
6. 아래 미리보기와 실행 기록을 확인한 후 **선택 보고서 PDF 저장**을 누릅니다. PDF에는 비교표, Python Matplotlib 그래프 7종, AI 해석, 공식 지침 인용, 체크리스트, 보완사항과 한계가 들어갑니다. PDF 재출력에는 새 AI 호출이 없습니다.

키가 없거나 외부 전송을 원하지 않으면 **키 없이 기본 PDF 저장**을 사용할 수 있습니다. `gradual_v1 기준 평가`와 원시 예측이 없는 과거 결과는 이 기본 출력 경로를 사용합니다. 현재 AI 에이전트 경로는 선택 모델의 원시 예측이 있는 검증된 비교 보고서에 연결됩니다.

## 연결 방식의 범위

- API 키는 Windows 자격 증명 저장소에 저장합니다. 프로젝트·로그·PDF에 저장하지 않으며 저장 후 입력란을 비웁니다. 키 삭제와 로그아웃도 설정 화면에서 가능합니다.
- ChatGPT는 로컬/오픈소스 앱용 공식 SIWC 로그인, 앱 자체 동적 등록, PKCE 및 서명 검증을 사용합니다. 설치된 Codex의 인증 정보를 가져오지 않습니다. 계정·워크스페이스의 사용 자격과 직접 플랜 권한이 있어야 추론을 실행합니다.
- Claude는 Anthropic API 키로 연결합니다. 이 앱에서 Claude.ai 구독 로그인을 제공하거나 구독 인증 정보를 가져오는 방식은 구현하지 않습니다.
- 연결 실패 시 다른 제공자나 과금 방식으로 자동 전환하지 않습니다.

## 에이전트 실행과 검증

성능 분석·지침 검토·보고서 작성은 같은 선택 스냅샷을 공유하는 별도 역할입니다. 실행 체계는 호출 수, 허용 도구, 시간, 출력, 재시도와 중단을 제어합니다. 도구는 집계 지표 읽기, 이미 승인된 지침 출처의 검색, 인용 근거 읽기에 한정됩니다. 모델 학습·원자료 수정·임의 셸 실행 기능은 없습니다.

수치는 Python에서 계산하고 AI에는 정해진 주장 ID와 연결합니다. 생성 문장에 임의의 수치를 넣거나 근거에 없는 모델·출처를 인용하면 실패 처리합니다. 본문은 실험·선택·문헌·실행 기록의 해시에 연결되고 PDF 저장 시 재검사합니다. 해시 검사는 자료 일관성을 확인하며 자연어 의미 전체나 임상 타당성을 보증하지 않습니다. TRIPOD+AI 관련 보고 상태와 PROBAST+AI 최종 편향 판단을 구분합니다.

집계 성능, 모델 선택, 보고 목적, 체크리스트·한계, 실행 식별자, 지침 발췌와 앞선 에이전트 분석을 선택한 서비스에 보냅니다. 원시 참여자/수면 기록과 로컬 원자료 경로는 보내지 않습니다. 보고 목적에도 개인 식별 정보를 입력하지 마세요.

API는 기본 최대 6회, 호출당 최대 90초, 전체 에이전트 실행 최대 300초로 제한합니다. 설정한 USD 예산은 사용자가 입력한 토큰 단가에 따른 추정이며 공급자의 최종 청구액을 보증하지 않습니다. ChatGPT 구독 경로는 출력 토큰 한도와 API식 USD 예산을 지원하지 않아 해당 설정을 비활성화합니다. 호출 수·시간·응답 2MB 제한을 적용합니다. 중단 전 이미 전송한 요청은 처리되거나 과금될 수 있으며, 진행 중인 네트워크 읽기는 타임아웃까지 기다릴 수 있습니다.

실행 감사 기록은 프로젝트의 `research/agent_runs/`에 저장합니다. 성공·실패·취소, 역할, 도구 호출, 제공자·모델, 요청 ID, 사용량(반환 시), 근거/응답 해시를 기록합니다. 비밀값과 원시 API 응답은 저장하지 않습니다. 비용을 알 수 없으면 `null`로 기록합니다. 실패나 취소 전에 만든 기본 근거 보고서는 최근 보고서에 남을 수 있으나 AI 성공 보고서로 표시하지 않습니다.

## 이번 검증 범위

API 키·계정 로그인 없이 모의 전송, 공식 로그인 계약, 인증 실패·취소·토큰 갱신, 에이전트 도구 제한, 수치/출처 변조 차단, Tk 화면과 PDF 연결을 시험했습니다. 실제 저장된 CMI 실행에서 모델 3개의 집계 수치와 그림 7종이 PDF까지 일치하는 것을 확인했습니다. 시험 문장은 `모의·시험 실행`으로 표시했습니다.

실제 계정의 로그인 성공, 플랜 사용 자격, API 모델 생성 품질과 실제 청구는 아직 검증하지 않았습니다. 실제 사용 시 사용자의 연결 설정이 필요합니다. 모의 시험 통과를 실제 API 성공이나 외부·전향 검증으로 해석하지 않습니다.
