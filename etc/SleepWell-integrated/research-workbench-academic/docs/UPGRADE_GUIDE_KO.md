# 고도화 기능 사용 가이드

## 설치 및 실행

지원 기준은 Windows 10/11 64비트, Python 3.12 64비트, CPU다. 프로젝트 전용 환경을 사용하므로 먼저 이 폴더에서 `install.cmd`를 실행하고, 설치 후 `launch.cmd` 또는 바탕 화면의 **SleepWell Academic Workbench** 바로가기를 실행한다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Recreate
.\.venv\Scripts\python.exe -m researchbench --project ".\deliverables\upgrade_examples\demo.swa"
```

문제가 있으면 `diagnose_windows.cmd`를 실행한다. GPU는 지원·검증 범위가 아니다.

## 작업 공간

- **SleepWell 연구**: 기존 수리·데이터·융합 모델과 후향·개인화·전향 평가를 실행한다.
- **일반 정형 데이터**: 기존 네이티브 `Toplevel` 창을 열어 분류·회귀 실험을 수행한다. 이 창의 일반 프로젝트를 근거/보고서 화면의 **일반 프로젝트 연결**로 읽기 전용 연결할 수 있다.
- **근거 문서 / 보고서**: 두 엔진의 완료 run을 소비하지만 원본 run과 프로젝트 형식은 변경하지 않는다.

## 문서 등록과 검색

1. **근거 문서**에서 PDF, DOCX, Markdown 또는 텍스트 파일을 선택한다.
2. 제목, 저자/기관, 버전, 분야, 권리 정보를 확인한다. URL/DOI만 등록한 경우 메타데이터 전용임을 유지한다.
3. 텍스트 추출 상태와 원본 해시를 확인한다. 스캔 PDF에 텍스트가 없으면 OCR 필요로 표시되며 자동 OCR은 제공하지 않는다.
4. 검색어와 언어·분야 필터를 입력한다. 기본 검색은 lexical이며 점수는 관련성이지 사실 확률이 아니다.
5. 결과의 짧은 발췌와 page/section/paragraph 위치를 확인한 뒤 필요한 항목만 보고서 근거로 연결한다. 근거가 없으면 부족 상태를 유지한다.

선택적 local embedding은 `install_optional_ai.cmd`와 `tools\prepare_embeddings.py`로 별도 준비한다. 현재 고정 평가에서 no-evidence 기준을 통과하지 못했으므로 hybrid는 실험적이며 기본 검색이 아니다.

## 보고서 만들기

1. **보고서**에서 연구 보고서, 산업 검증 보고서, 모델 카드 또는 실험 비교 메모를 선택한다.
2. 실제 완료 run을 하나 이상 선택한다. 서로 다른 task/target/평가 대상을 하나의 순위로 합치지 않는다.
3. 연구 분야, 독자, 의도한 사용, 사전 수용 기준을 입력한다. 수용 기준을 실행 전에 정했다면 해당 항목을 명시한다.
4. 의료 예측 연구인 경우에만 의료 예측 옵션을 선택한다. 이 선택은 TRIPOD+AI 적용 가능성 검토를 열 뿐 인증이나 전체 체크리스트 충족을 의미하지 않는다.
5. 연결할 문헌 검색 결과를 선택하고 초안을 생성한다.
6. 왼쪽 섹션/claim 목록, 가운데 편집문, 오른쪽 실험 값·문헌 위치·검사 결과를 확인한다.

수치 claim은 원본 run의 정확한 field path, 단위와 분모에 연결된다. 편집은 기존 버전을 덮어쓰지 않고 새 버전을 만들며 다시 검사해야 한다. 사용자 검토는 검토자 이름과 메모를 별도로 기록하며 자동 검사와 구분된다.

## 검사 및 내보내기

- 수치 불일치, 추가로 삽입된 근거 없는 숫자, run 해시 변경, 조작된/폐기된 인용은 차단 오류다.
- 의미상 지지는 사람이 확인해야 한다. 자동 검사 통과는 전문가 검증, 규제 적합성 또는 인증이 아니다.
- 초안은 경고 표시를 포함해 내보낼 수 있다. 검사 통과본은 차단 오류가 없어야 한다.
- Markdown, DOCX, 전체 보고서 PDF, 감사 JSON, BibTeX, CSV와 실제 예측이 있는 경우 그림을 내보낼 수 있다.
- 언어 변경은 같은 근거의 새 보고서 버전을 만들며 기존 사용자 편집본을 덮어쓰지 않는다.

## 해석 시 주의사항

- `deliverables\upgrade_examples`의 자료는 모두 합성 또는 라이선스가 명시된 fixture이며 소프트웨어 시연 전용이다.
- 저장된 과거 검증표는 새 학습이나 외부 재평가가 아니다.
- 외부 평가는 최종 모델·전처리·스키마를 먼저 동결하고 모델 선택에 쓰지 않은 별도 데이터를 사용할 때만 해당한다.
- 반복 측정은 행 수와 독립 참여자 수를 구분한다. 표본 수가 작거나 원시 예측이 없으면 불확실성 또는 하위집단 통계를 만들지 않는다.
- 중첩 교차검증, GPU, 실제 외부 LLM 호출, 로컬 생성 모델, OCR은 완료 기능으로 표시하지 않는다.
