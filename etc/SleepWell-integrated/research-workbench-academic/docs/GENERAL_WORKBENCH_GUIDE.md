# 일반 정형 데이터 Research Workbench 안내

이 문서는 학술제 전용 복제본을 만들기 전 일반판 README의 기능·설치·평가 원칙을 보존한다. 현재 시작 화면은 SleepWell 학술제 전용이며, 일반 분류·회귀 도구는 상단의 `일반 정형 데이터 실험` 버튼으로 별도 네이티브 창에서 연다. 독립 원본 일반판은 `../research_workbench`에 그대로 남아 있다.

## 제품 범위

일반판은 CSV·Excel 정형 데이터로 분류와 회귀 실험을 설계하고 비교하는 Windows 설치형 프로그램이다. Tkinter 안에서 pandas 표와 Matplotlib 그림을 표시하며 외부 API 없이 로컬 CPU에서 학습한다.

- Python 3.12 + Tkinter 네이티브 GUI
- pandas + openpyxl 데이터 읽기와 품질 확인
- scikit-learn `Pipeline` / `ColumnTransformer` 기반 누수 방지
- 더미·선형·랜덤 포레스트·간단한 MLP
- 무작위·그룹·시간 분할과 교차검증
- 프로젝트 폴더 저장, PNG/PDF/SVG 및 CSV/XLSX 내보내기
- 별도 프로세스 실행과 취소 상태 구분

CPU가 검증된 기본 장치다. GPU 학습은 구현·검증되지 않았으며 설치 여부만으로 GPU 지원을 표시하지 않는다.

## 일반 실험 흐름

1. CSV 또는 Excel을 불러온다.
2. 타깃과 분류·회귀 작업 유형을 사용자가 확정한다.
3. 입력 피처, ID, 그룹, 시간, 제외 열을 지정한다.
4. 최종 테스트 비율, 검증 fold, 시드, 모델과 전처리를 정한다.
5. 기준 실험을 실행한다.
6. 기준 실험을 복제해 피처 하나를 제거하거나 조건 하나를 바꾼다.
7. 같은 데이터 버전·분할·시드를 사용한 결과끼리 비교한다.
8. 모델 선택이 끝난 뒤 작업별 최종 테스트를 한 번 평가한다.

분류와 회귀의 지표를 합산해 하나의 우승 모델을 만들지 않는다. 정확도 차이는 퍼센트포인트와 상대 변화율을 구분하고, 피처 제거 결과를 인과 효과로 설명하지 않는다.

## 누수 방지와 지표

결측치 대체, 인코딩, 스케일링과 학습형 타깃 변환은 각 학습 fold 안에서만 적합한다. 최종 테스트 행은 검증 예측, 피처 선택, 하이퍼파라미터와 임계값 선택에 사용하지 않는다.

분류는 ROC-AUC, Average Precision, 정확도, Balanced Accuracy, 재현율, 특이도, 정밀도, F1과 혼동행렬을 제공한다. ROC-AUC는 확률 또는 연속 점수로 계산하며 임계값 기반 지표에는 임계값을 기록한다. 회귀는 MAE, MSE, RMSE, R²를 원 단위에서 계산한다. 계산할 수 없는 지표는 0으로 바꾸지 않고 이유를 남긴다.

fold 표준편차는 fold 간 변동이지 신뢰구간이 아니다. 단일 결과를 박스플롯으로 표현하지 않는다.

## 일반판 샘플

`samples/`에는 다음 합성 데이터가 있다.

- `classification_mixed.csv`: 이진 분류
- `regression_mixed.xlsx`: 연속형 회귀
- `dual_tasks.csv`: 분류·회귀 병렬 연구 질문
- `multiclass_mixed.csv`: 다중 분류

모두 실제 참여자 자료가 아닌 고정 시드 합성 데이터다.

## 일반판 프로젝트와 재현성

프로젝트에는 데이터 해시, 열 역할, 분할 행 ID, 시드, 전처리·모델 설정, 라이브러리 버전, 장치, fold 지표와 예측값이 저장된다. 원본 파일은 수정하지 않는다. 완료된 실험은 같은 ID로 덮어쓰지 않으며, 실행 중 종료된 상태는 재열기 때 `중단됨`으로 복구한다.

한국어와 English는 재시작 없이 전환된다. 자동 생성 그림과 표는 현재 언어를 따르지만 원본 열 이름, 범주 값, 사용자가 쓴 제목과 실험 이름은 자동 번역하지 않는다.

## 설치와 일반판 검증

원본 일반판은 Windows 10/11 64비트와 Python 3.12 64비트를 기준으로 프로젝트 전용 `.venv`를 사용한다. 분류·회귀 기준 및 피처 제거 예제는 다음 형태로 실행한다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m examples.end_to_end --output .\example_output_manual
```

예제 명령은 같은 출력 프로젝트가 이미 있으면 덮어쓰지 않는다. 실제 검증 수와 산출물은 원본 일반판의 `VALIDATION.md`와 `deliverables/examples/`를 확인한다.

## 일반판의 기존 제한

- 정형 데이터만 지원
- 초기 UI에는 중첩 교차검증 없음
- 단일 워커로 한 실험씩 실행
- 별도 외부 테스트 파일 결합, 생존분석, 혼합효과 모형, 인과 추론은 범위 밖
- MAPE는 0 근처 타깃 문제 때문에 기본 지표에서 제외
- Python 런타임이 필요한 프로젝트 전용 환경 방식이며 단일 EXE가 아님
- Windows OS 배율별 사람 기준 육안 검증은 자동 Tk 배율 검사와 별개

일반판의 상세 개발 기록과 예제는 보존된 `../research_workbench/README.md`, `VALIDATION.md`, `deliverables/examples/`를 기준으로 한다. 이 학술제 복제본의 모델 결과와 일반 scikit-learn 결과는 같은 종합 점수로 합치지 않는다.
