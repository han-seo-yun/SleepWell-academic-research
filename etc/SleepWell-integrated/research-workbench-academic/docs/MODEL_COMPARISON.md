# 모델 비교 탭

SleepWell은 예측 기준 시점 이후의 취침·기상 시각을 분 단위로 예측하는 회귀 모델이다. 기본 화면의 **모델 실험 · 시각화**에서 완료 결과를 선택하면 아래 탭을 사용할 수 있다. 모든 그래프는 Python의 Matplotlib `Figure`로 계산·렌더링하며 Tk 캔버스에 표시한다. PNG·PDF·SVG 저장도 같은 Figure를 사용한다.

| 탭 | 의미 | 해석 |
| --- | --- | --- |
| MAE | 절대 오차의 평균(분) | 작을수록 좋음 |
| RMSE | 제곱 오차 평균의 제곱근(분) | 큰 오차에 민감하며 작을수록 좋음 |
| 오차 방향 | 예측−실제의 평균(분) | 시각: 음수는 이르게, 양수는 늦게 예측. 구간: 음수는 짧게, 양수는 길게 예측 |
| 허용오차 내 비율 | 절대 오차가 선택한 15·30·60분 이하인 비율 | 클수록 좋음. 탐색용 기준이며 임상 기준이나 분류 정확도가 아님 |
| 실제·예측 | 모델별 산점도와 일치선 | 같은 축 범위에서 일치선에 가까운 정도 비교 |
| 오차 분포 | 밤별 부호 있는 오차의 분포 | 분산·극단값·방향 확인. 신뢰구간이 아님 |
| 참여자별 | 참여자별 MAE | 사람 간 차이를 확인. 소수 표본의 우열을 확정하지 않음 |
| ROC·분류 지표 | 현재 적용되지 않는 지표와 그 이유 안내 | 계산값을 만들어 내지 않음 |

`예측 대상`에서 취침 시각·기상 시각·취침–기상 구간을 고른다. 구간은 기상과 취침의 차이이며 PSG로 측정한 총 수면시간으로 해석하지 않는다. 시각은 공통 예측 기준 이후의 분 오프셋이므로 시계의 자정에서 차이를 끊거나 임의의 순환 오차로 바꾸지 않는다.

`비교 모델 선택`에서 각 모델을 켜거나 끌 수 있다. 선택한 모든 모델의 유효한 예측이 있는 **동일 참여자·동일 예측 시점**만 비교한다. 모델 선택이나 예측 대상을 바꾸면 공통 평가 집합도 달라질 수 있다. 사용한 밤 수·참여자 수·제외된 기록 수를 표시한다. 같은 관측의 정답이 모델마다 다르거나 한 모델에서 관측 키가 중복되면 계산을 중단한다. 원시 예측이 없는 과거 결과에서는 새 지표를 추정하지 않는다.

기본 집계는 **참여자 동일 가중**이다. 각 참여자의 MAE·RMSE·평균오차·허용오차 내 비율을 먼저 구하고 참여자 간 산술평균한다. 따라서 기본 RMSE는 참여자별 RMSE의 평균이며 전체 밤을 한 번에 합쳐 계산한 RMSE와 다를 수 있다. 이는 기존 SleepWell의 참여자 단위 집계와 맞춘 정의다. `밤 동일 가중`은 모든 공통 밤에 같은 가중치를 부여한다. 반복 측정의 독립성을 가정한 신뢰구간이나 유의확률을 생성하지 않는다.

`비교 지표 저장`은 현재 대상·모델·집계·허용오차 설정의 수치와 실행 ID를 CSV/Excel로 저장한다. 기존 실행 파일과 원래 성능 요약은 변경하지 않는다. 재계산한 탐색 비교를 새로운 전향 검증이나 외부 검증으로 표현하지 않는다.

## 선택한 비교를 보고서로 출력

[비교 보고서 구현·검증 기록](SELECTED_MODEL_REPORT.md)

1. **모델 실험·시각화**에서 완료 실행, 비교할 모델, 예측 대상, 집계 방식과 허용오차를 선택한다.
2. **RAG 보고서**에서 같은 완료 실행을 선택한다. 화면에 보고서에 들어갈 모델과 설정이 표시된다.
3. **근거 검색 후 PDF 저장**을 누른다. 버튼을 누른 시점의 선택을 고정해 비교표와 Matplotlib 그래프 7종을 함께 출력한다.

선택은 실행별로 보관한다. 비교 화면에서 설정하지 않은 실행은 그 실행의 전체 모델·취침 시각·참여자 동일 가중·±30분을 사용하고 보고서 화면에 이를 명시한다. 모델을 모두 해제하면 보고서를 생성할 수 없다. 다른 실행의 선택을 가져오거나 해제한 모델을 다시 포함하지 않는다.

보고서는 MAE 점추정치가 가장 작은 모델과 다음 순위와의 차이를 설명하고, RMSE·허용오차 내 비율의 순위가 다른지도 보여준다. 동률이면 단독 우승 모델을 정하지 않는다. 단일 모델은 성능만 설명한다. 신뢰구간이나 임상적 허용 기준이 없으면 통계적·임상적 우월성을 주장하지 않는다.

TRIPOD+AI의 비교 보고 관련 항목과 PROBAST+AI의 검토 영역을 연결하고, 현재 자료로 보완할 분석, 연구자 확인이 필요한 메타데이터, 독립 외부 자료가 필요한 일반화 평가를 구분한다. 이 표는 전체 지침의 완료 판정이나 편향 위험의 자동 최종 판정이 아니다. 공식 지침의 로컬 검색 근거는 문헌 제목·페이지·링크와 함께 보존하며 성능값은 원 실행에서 재계산한다. 생성형 LLM과 외부 AI 전송은 사용하지 않는다.

보고서 생성과 출력 시 원 실행의 해시·선택 설정·재계산 지표·해석의 일치 여부를 확인한다. 변경되거나 잘못 연결된 결과는 출력을 중단한다. 보고서에는 참여자별 원래 식별자와 원시 예측 행을 포함하지 않는다.

## 분류 지표를 계산하지 않는 이유

ROC-AUC에는 사전에 정의된 분류 정답과 연속 예측 점수가 필요하다. 민감도·특이도·정확도에는 분류 정답과 분류 결정이 필요하다. 현재 SleepWell 결과에는 이러한 라벨·점수가 없으므로 회귀 예측을 임의로 좋음/나쁨으로 나누지 않는다. 추후 별도로 정의하고 검증한 분류 과제가 있을 때 그 결과 형식과 평가 절차를 추가해야 한다.

## 구현 및 확인 기록 (2026-11-05)

계산은 `researchbench/comparison_metrics.py`, Matplotlib 그래프는 `researchbench/comparison_plotting.py`, 화면 연결은 `researchbench/simple_workflow.py`에 있다. 기존 선택 상자 방식의 그래프 전환을 지표 탭으로 교체하고 계산·그림·화면 회귀 검사를 추가했다. 새 의존성이나 모델·가중치 변경은 없다.

통합 검사 122개와 마지막 UI 검사 3개가 통과했고 `compileall`을 확인했다. 독립 검토에서 발견한 비율 축·제외 건수 표시·한글 표시 문제를 수정하고 재확인했다. 별도 lint/typecheck 설정은 없으며 Ruff는 설치되어 있지 않다.
