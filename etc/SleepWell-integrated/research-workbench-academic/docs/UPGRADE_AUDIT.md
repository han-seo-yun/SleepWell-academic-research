# 고도화 구현 감사 기록

기준일: 2026-11-01  
대상: `research_workbench_academic`

이 문서는 기존 결과의 재현성을 보존하면서 추가한 연구 근거·보고 기능의 실제 구현 범위와 검증 한계를 구분한다. 합성 예제는 소프트웨어 동작 검증용이며 연구 성능, 산업 적용 성능, 임상적 유효성 또는 외부 타당성의 근거가 아니다.

## 변경 전 기준선

- Windows 11, Python 3.12.1에서 기존 테스트 `113`개가 `78.600s`에 통과했다. 원 로그는 `deliverables/upgrade_validation/baseline/unittest_baseline.log`에 있으며 SHA-256은 기준선 JSON에 기록되어 있다.
- 기존 `.swa` schema 1, 일반 프로젝트 `format_version` 1, SleepWell 원본 엔진·입력 스냅샷·완료 run, vendored 원본은 변경 대상에서 제외했다.
- 보호 파일과 결정론적 실험 결과는 `tools/verify_upgrade_baseline.py --check`로 기준선과 비교한다.

## 기존 지원 — 보존한 기능

- Tkinter/Matplotlib 기반 Windows 네이티브 GUI, 한국어·영어 전환, CPU 실행.
- 일반 정형 데이터 분류·회귀, fold 내부 전처리, 최종 테스트 분리, 그룹·시간 분할, 피처 변경 비교, 저장·재열기.
- SleepWell 후향·개인화·합성 전향 재생·실제 전향 journal과 원본 모델/평가 규칙.
- 입력 및 완료 결과 해시, 완료 run 불변 저장, 저장된 과거 검증표와 새 계산의 구분.
- 일반 정형 데이터 작업 공간은 기존 네이티브 `Toplevel` 창을 그대로 열며, 보고서용으로 일반 프로젝트를 읽기 전용 연결한다. 두 엔진의 저장 원본을 합치거나 다시 쓰지 않는다.

## 개선한 기능

- SleepWell·일반 run을 공통 읽기 전용 결과 view로 정규화하고 task, target, split, population, synthetic/calculation/evaluation type, metric 단위·분모·원본 field path를 보존한다.
- 여러 run의 비교 가능성을 같은 평가 대상·설계·단위·지표 정의 기준으로 판정하며, 불일치 시 참고 비교 또는 비교 불가로 표시한다.
- 프로젝트별 문서 라이브러리, 버전·해시·권한·locator·검색 감사를 저장하고 폐기·변경된 출처가 인용 검사를 통과하지 못하게 했다.
- 보고서에서 선택한 외부 일반 프로젝트 run은 원본을 수정하지 않고 `research/run_evidence/<result_hash>.json`에 검증된 불변 근거 사본으로 고정한다. 원본 위치·해시는 계속 기록하며, 접근 가능할 때 변경 여부를 다시 검사한다.
- 사용자 입력을 JSON 직접 편집 대신 구조화된 화면으로 제공하고, 한국어·영어 전환 중 작성 중인 초안과 선택을 유지한다.

## 신규 기능

- 연구 보고서, 산업 검증 보고서, 모델 카드, 실험 비교 메모의 결정론적 구조화 초안.
- 실험 수치 claim의 run ID/result hash/field path/value/unit/n_rows/n_participants 연결과 문헌 claim의 source version/chunk/anchor/search ID/짧은 발췌 연결.
- 편집 시 새 불변 버전 생성, 자동 검사와 사람 검토 기록 분리, 같은 근거를 유지한 새 언어 버전 생성.
- NIST AI RMF와 Model Cards를 참고한 검토 항목. 상태는 충족/부분 충족/미충족/해당 없음/판단 보류로 구분하며 인증으로 표시하지 않는다.
- 사용자가 의료 예측 연구임을 명시한 경우에만 TRIPOD+AI 적용 가능성 검토 항목을 `판단 보류`로 연다. 검증하지 않은 세부 항목을 자동 생성하지 않는다.
- Markdown, DOCX, 전체 보고서 PDF, 감사 JSON, BibTeX, CSV, 예측 그림과 재현 manifest 내보내기.
- 동결 모델 외부 평가, 독립 단위 bootstrap/paired 비교, 분류 보정·회귀 잔차·하위집단 분석 및 다중 참여자 전향 상위 계층. 원시 예측이 없는 저장 보고서에는 새 통계를 만들지 않는다.
- 외부 API 전송 전 미리보기·명시 승인·예산·자격증명 저장·감사 경계와 결정론적 테스트 transport.

## 검증 결과와 해석 경계

- 최종 전체 테스트 `200`개가 Windows 11/Python 3.12에서 `107.503s`에 통과했다. 보고서 전용 테스트에는 교차 프로젝트 run 고정, 단위·행/참여자 분모 변조, 수치 문구와 자유 서술 숫자 변조, 출처 변경·폐기, 불변 버전, 한/영 동일 근거, DOCX/PDF 본문 표·그림과 PNG/PDF/SVG 산출 검사가 포함된다. 연속 다국어 PDF의 glyph 누락을 문서별 렌더 프로세스로 수정했고, 공통 평가 대상/모델 색상/단위 및 분류 혼동행렬 회귀 검사를 추가했다. 상세 로그와 미검증 범위는 `deliverables/upgrade_validation/FINAL_VERIFICATION.md`에 기록했다.
- `tools/verify_upgrade_baseline.py --check` 결과는 `passed: true`, mismatch `0`으로 기존 보호 소스·저장 계약·결정론적 기준 결과의 회귀가 없었다.
- 예제 생성기는 합성 SleepWell 후향·개인화 run, 일반 분류·회귀 프로젝트, CC0 fixture 문서, 실제 검색, 4개 템플릿의 한/영 보고서와 내보내기를 생성한다.
- 기본 검색은 lexical이다. 선택적 다국어 임베딩의 고정 평가에서 answerable 4건의 Recall@3 `1.00`, MRR `1.00`이었으나 no-evidence 2건 중 `1/2`만 맞아 사전 기준을 통과하지 못했다. 따라서 hybrid 경로는 실험적이며 기본값이 아니다.
- 자동 검사는 구조, 수치 정합성, 출처 위치·해시·활성 상태를 검사한다. 발췌가 주장을 의미상 지지하는지에 대한 사람 표본 검토는 완료되지 않았고 자동 통과를 전문가 검토나 인증으로 표현하지 않는다.
- 동결 외부 평가는 학습 완료 전에 고정된 최종 파이프라인·스키마와 모델 선택에 사용되지 않은 별도 데이터가 있을 때만 외부 평가로 해석할 수 있다. 외부 데이터를 본 뒤 모델을 선택하면 새 실험 버전이다.
- 지원 평가 설계는 holdout이다. 튜닝을 포함한 중첩 교차검증은 구현·검증하지 않았다.

## 검증 불가 또는 미지원

- 실제 미래 코호트 또는 독립 외부 코호트가 제공되지 않아 실제 외부/전향 타당성은 검증하지 않았다.
- 이 세션에서는 실제 데스크톱 창을 자동 조작할 권한이 없어 Windows 배율 100%와 200%의 대화형 클릭 흐름은 검증하지 못했다. Tk withdrawn 기반 한/영 화면 테스트와 KO/EN PDF 렌더 검사는 수행했지만 실제 사용자 화면 검증을 대체하지 않는다.
- 외부 LLM API 키가 없어 실제 공급자 호출은 검증하지 않았다. 로컬 생성 모델 기반 서술도 구현하지 않았다.
- 스캔 PDF OCR은 구현하지 않았다. 텍스트가 없으면 OCR 필요/추출 실패로 표시하며 전문을 읽은 것으로 취급하지 않는다.
- GPU 실행, 중첩 교차검증, 규제 인증, 임상적 성능 보장은 지원 범위가 아니다.
- hybrid 검색은 위 no-evidence 수용 기준 실패로 최종 품질 통과를 주장할 수 없다.
