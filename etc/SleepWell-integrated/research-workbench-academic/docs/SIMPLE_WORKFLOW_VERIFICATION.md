## 남은 제한

- 사용자의 Esc 입력으로 컴퓨터 조작이 중단되었다. 이후 화면 조작을 하지 않았으며 실행 중인 기존 창을 재시작하지 않았다. 네이티브 창의 최종 시각 확인은 미완료다. 새 코드는 다음 실행에 적용된다.
- 현재 작업은 기존 자료의 탐색 실험이다. 새로운 전향 검증·독립 외부 검증을 수행한 것으로 해석하지 않는다.
- `all`은 코호트 필터 해제다. ID 순 첫 N명 선택으로 한 코호트만 포함될 수 있으며 실제 구성은 결과와 보고서에 기록한다.
- 보고서 생성은 로컬 검색과 결정적 서식을 사용한다. LLM 생성이나 자동 전문가 판정은 구현하지 않는다.
- 보고서 작업에는 별도 취소 버튼이 없으며 PDF 작업의 제한 시간은 180초다. 실행 중 앱 종료는 작업 정리를 기다릴 수 있다.
- 입력 검증은 현재 고정된 vendor의 비공개 검증 함수를 사용한다. vendor 버전 변경 시 입력 계약 회귀 검사가 필요하다.
