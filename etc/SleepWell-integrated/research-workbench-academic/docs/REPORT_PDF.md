# 보고서 화면에서 PDF 저장

기본 보고서 화면은 결과 선택, 선택적 AI 연결·분석, 미리보기와 PDF 출력을 제공합니다. [AI 보고서 사용법](AI_REPORT_WORKFLOW.md)

[선택 모델 비교 보고서 변경·검증 기록](SELECTED_MODEL_REPORT.md)

- **결과 선택**: 성능 지표가 있는 완료 실험 또는 `gradual_v1` 기준 평가를 명시적으로 고릅니다. 완료했어도 성능 지표가 없는 진단 실행은 선택지에 나타나지 않습니다.
- **보고 목적**: 필요한 경우 한 줄로 입력합니다.
- **키 없이 기본 PDF 저장**: 공식 지침 원문의 해시를 확인하고 로컬 검색 근거를 첨부한 뒤 자동 검사를 수행하고 PDF를 저장합니다.
- **AI 연결 설정**: API 키 입력·삭제, ChatGPT 공식 로그인·로그아웃, 모델 목록·연결 확인, 실행 한도를 설정합니다.
- **AI 근거 분석·보고서 작성**: 선택 모델에 대한 세 에이전트의 분석과 자동 검사를 실행해 새 보고서 버전을 만듭니다. 중단할 수 있으며 실패를 성공이나 기본 보고서로 바꾸지 않습니다.
- **선택 보고서 PDF 저장**: 미리보기에서 선택한 보고서를 PDF로 저장합니다. 저장할 때 AI를 다시 호출하지 않습니다.
- **최근 보고서**: 자료 출처, 검사 상태, 검증된 성능 항목 수와 검색 근거 수를 읽기 전용으로 보여줍니다.
- **마지막 PDF 열기**: 이번 작업에서 저장한 PDF를 엽니다.

실험 결과를 선택하면 **모델 실험·시각화**에서 해당 실행에 선택한 모델·예측 대상·집계 방식·허용오차를 그대로 사용합니다. 보고서 화면에서 이 설정을 미리 확인할 수 있습니다. 비교표, Matplotlib 그래프 7종, MAE 기준 조건부 순위와 다른 지표의 차이, 표본·불확실성·일반화의 한계가 자동으로 들어갑니다. 단일 모델이면 모델 간 우열 판단을 생략합니다. 빈 모델 선택은 생성을 차단합니다. [비교 설정과 지표 해석](MODEL_COMPARISON.md)

선택 비교 보고서는 TRIPOD+AI 관련 보고 항목과 PROBAST+AI 검토 영역을 근거에 연결하고, 현재 자료로 보완할 부분·메타데이터 및 연구자 확인·외부 자료가 필요한 부분을 구분합니다. 전체 지침 충족이나 낮은 편향 위험을 자동 선언하지 않습니다. 수치와 해석은 동결된 실행 및 선택의 해시를 재검사하고, 공식 지침 검색 결과에는 문헌 제목·페이지·링크를 붙입니다.

비교 화면에서 아직 선택하지 않은 실행은 전체 모델·취침 시각·참여자 동일 가중·±30분을 기본으로 사용하며 화면에 표시합니다. 원시 예측이 없는 과거 실행은 보관된 성능 지표 보고서를 사용하고 새 비교값이나 그래프를 추정하지 않습니다. `gradual_v1` 기준 평가를 선택했을 때는 별도로 저장된 기준 평가와 전체 TRIPOD+AI·PROBAST+AI 점검 결과를 사용합니다. 검색 결과는 수치를 만들거나 바꾸지 않습니다.

기존 상세 편집·체크리스트 화면의 저장 자료와 서비스 코드는 호환성을 위해 유지하지만 기본 3단계 화면에서는 노출하지 않습니다.

상세 보고서 화면에서는 아래 기능도 지원합니다.

- **gradual_v1 자동 보고서 · PDF 저장**: 실행을 선택하지 않아도 현재 `gradual_v1` 집계 평가와 TRIPOD+AI·PROBAST+AI 점검 근거를 연결합니다. 성능과 불확실성, 전체 점검 항목, 보완사항, 외부 자료가 필요한 부분을 채운 새 문서와 PDF를 만듭니다. 이전 문서는 보존합니다.
- **새 보고서 생성 · PDF 저장**: 기본 `gradual_v1` 템플릿은 같은 자동 채움 경로를 사용합니다. 다른 일반 템플릿은 완료 실행을 선택해야 합니다. 저장창을 취소하면 문서도 생성하지 않습니다.
- **문서 초안만 생성**: PDF 없이 편집용 문서 버전을 만듭니다.
- **선택 보고서 PDF 저장**: 기존 문서 버전을 지정한 PDF 파일로 저장합니다. 저장하지 않은 편집 내용은 먼저 새 문서 버전으로 저장해야 합니다.
- **저장한 PDF 열기·인쇄**: 현재 선택한 문서 버전에서 저장한 PDF를 엽니다. PDF 뷰어의 Ctrl+P로 인쇄합니다.
- **TRIPOD·PROBAST 점검 보고서**: 모델 점검·보고서 탭으로 이동합니다.
- **공식 지침 PDF 자료실**: 공식 원문 다운로드·저장·열기와 SleepWell 적용 안내로 이동합니다.

PDF는 기존 보고서 검사, 초안 표시, 실험 수치와 그림을 유지합니다. 검사 통과본을 선택해도 오류가 있으면 내보내기를 차단합니다. 출력은 선택한 저장 버전을 대상으로 하며, 기존 문서·실험 결과를 수정하지 않습니다. 같은 이름의 파일은 덮어쓰지 않습니다.

PDF 저장 중 실패해도 이미 생성된 문서 초안은 버전 목록에 남습니다. 파일 경로를 바꾼 뒤 상단의 PDF 저장을 다시 사용할 수 있습니다.

공식 지침 근거 검색은 번들 원문 PDF의 해시를 확인하고 관련 페이지와 검색 기록을 연결합니다. 기본 PDF는 로컬 검색과 서식 작성만 사용합니다. 선택적 AI 경로는 집계 보고서 맥락을 선택한 서비스로 전송하며 생성 방식·제공자·모델·실행 기록을 별도로 표시합니다. 수치와 체크리스트 상태는 동결된 평가·감사 기록에 고정하며 AI가 변경하지 않습니다. 이전 검색 구현 설명은 [GUIDELINE_RAG.md](GUIDELINE_RAG.md)를 참고하십시오.

자동 검사는 근거와 문서의 일치 여부를 확인합니다. TRIPOD 충족이나 PROBAST 위험에 대한 최종 전문가 판단을 대신하지 않습니다. 재사용 holdout 평가를 독립 외부 검증으로 표시하지 않으며, 외부 자료의 실제 확보·분석과 연구자 확인이 필요한 사항은 남은 과제로 표시합니다.
