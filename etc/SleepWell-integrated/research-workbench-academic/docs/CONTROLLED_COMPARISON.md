# CMI·MESA 동일조건 비교 실험

2026-11-04 감사에 따라 원 DB와 기존 사람 단위 분할을 유지하면서 네 학습 전략을 비교한다. 이번 실험은 이미 검토한 Test의 재사용 후향 실험이며 독립 검증으로 취급하지 않는다.

| 전략 | prior·전처리 적합 자료 | 회귀기 적합 자료 | 출처 인코딩 |
|---|---|---|---|
| separate | CMI/MESA 각각의 Train만 | 각 출처의 Train만 | 없음 |
| pooled | 양 출처 Train | 양 출처 Train | 없음 |
| pooled_source | 양 출처 Train | 양 출처 Train | CMI/MESA 두 one-hot 열 |
| separate_shared | 양 출처 Train | 각 출처의 Train만 | 없음 |

`separate`는 모든 적합 단계가 출처별로 분리된 비교군이다. `separate_shared`는 공통 prior·전처리를 고정하고 회귀기를 분리했을 때를 비교하는 보조군이다. 따라서 후자를 순수 개별 학습으로 부르지 않는다.

## 동일 조건과 선택 규칙

- 원 Train 안에서 코호트별 사람 단위 3분할을 독립 seed로 두 번 반복한다. 같은 사람의 밤은 같은 fold에 속하고 각 반복에서 한 번만 보류한다. fold마다 prior, 특징 재생, 전처리, 모델을 새로 적합한다.
- 후보는 기존과 같은 Ridge 2종·Huber·HGB 3종이다. 모든 전략은 같은 후보 설정을 사용한다. 별도 모델은 두 회귀기 묶음, 공통 모델은 하나의 묶음이므로 전체 파라미터 수가 같다는 의미는 아니다.
- 전처리는 가중 중앙값 대치·상수열 제거·가중 표준화를 공통으로 사용한다. clipping 없음 / 가중 0.5–99.5백분위 / 가중 1–99백분위를 비교한다. 가중 백분위는 동점 질량을 합친 경험 누적분포의 역함수로 정의한다.
- 공통 적합에서는 각 코호트 총 가중치 50%, 각 코호트 내 사람 총 가중치 동일이다. 출처별 적합에서는 해당 출처 내 사람을 균등하게 취급한다. 추정기마다 sample weight의 평균을 1로 정규화한다. 규제 파라미터는 같은 값을 사용하며 자료량에 따른 규제의 실효 차이를 별도로 최적화하지 않는다.
- 33개 수면 이력 특징(DATA33)을 주 분석으로 정한다. 각 설정의 separate/pooled 평균 CV macro MAE가 가장 작은 **공통 설정 하나**를 선택한다. 이 설정을 네 전략과 DATA33/HYBRID39 모두에 적용한다. 전략별 최적화나 hybrid 특화 최적화 결과라고 주장하지 않는다.
- 원 Validation은 잠긴 모델의 진단 평가에만 사용한다. 최종 모델도 원 Train만 적합하며 Validation을 합쳐 재학습하지 않는다. 모든 모델 파일과 공통 설정을 해시로 잠근 뒤 Test 특징과 점수를 생성한다.
- 주요 비교는 `separate_data` 대 `pooled_data`의 CMI/MESA 50:50 macro MAE다. 나머지 출처·인코딩·descriptor 비교는 보조 탐색 분석이다. 자동 승자 선정이나 기존 모델 교체는 하지 않는다.

## 인코딩과 디스크립터

- 디스크립터는 모델에 넣는 설명 특징이다. 최근 수면 시각·중앙값·변동성·추세·이력 길이 등이 이미 DATA33에 포함되어 있다.
- HYBRID39는 같은 33개에 수리적 수면 상태·전환 기준·예측 특징 6개를 더한다. 별도의 측정 생리값이 아니며 동일 조건의 추가 특징 실험이다.
- 요일은 기존 sin/cos 주기형 특징과 주말 이진 특징을 유지한다. 시각은 결정시점 20:00으로부터의 경과 분으로 표현해 자정 통과를 처리한다. MESA의 재구성 연도·계절은 입력하지 않는다.
- 출처 one-hot은 숫자 순서나 목표값 통계를 주입하지 않고 전처리 후에 0/1로 추가한다. 이 열은 clipping/표준화 대상이 아니며 알려지지 않은 새 출처는 거부한다. 이 표현은 알려진 두 출처 간 조건부 차이를 다루며 새 장치로의 일반화를 보장하지 않는다.
- CMI는 연령·성별이 전부 결측이므로 이를 임의로 채워 공통 예측 변수로 쓰지 않는다. 참여자 ID도 인코딩하지 않는다.

## 이상치와 보고

상류의 주수면 추출·시간 범위 규칙은 이번 비교에서 고정한다. 큰 예측 오차나 Test 결과를 이유로 삭제하지 않는다. 3시간 미만·12시간 초과 구간은 사후 기술통계의 품질 검토 표식이며 정답 오류 판정 기준이 아니다.

성능은 사람별 평균을 먼저 구한 뒤 코호트 내 균등 평균하고, Macro는 CMI/MESA에 각각 절반을 준다. 5,000회 사람 단위 paired bootstrap은 학습된 모델 조건부 CI이며 모델 적합·선택 불확실성을 포함하지 않는다. CV fold 간 표준편차는 독립 표본의 표준오차나 검정용 CI로 해석하지 않는다.

Workbench는 코호트별 패널과 joint MAE CI, 짝지은 차이 CI를 제공한다. 잔차·개인별 MAE는 전체 범위 ECDF로 표시하고 잔차 분포도 참여자 균등 가중을 사용한다. 진단 그림에서 꼬리를 숨기거나 범위 밖 잔차를 경계값으로 몰지 않는다.

## 실행

`scripts/compare_cmi_mesa.py`는 AcademicQueue와 .swa 프로젝트에 실제 학습 실행을 저장한다. 새 `--output`, `--project` 경로가 필요하며 기존 실행을 덮어쓰지 않는다. UI의 데이터·실험 설정에서도 동일조건 비교를 시작할 수 있다.

## 2026-11-04 완료 결과

실행 `46335cfd-00ed-4c40-9df8-a41c0fddba89`가 완료됐다. 864개 CV 점수에서 공통 설정은 Huber 회귀와 절단 없음으로 선택됐다. 가중 대치·상수열 제거·가중 표준화는 유지된다. 같은 Test 359명·2,848밤에 최종 8개 모델을 평가했다.

| DATA33 전략 | CMI MAE(분) | MESA MAE(분) | Macro MAE(분) |
|---|---:|---:|---:|
| separate | 48.94 | 68.47 | 58.70 |
| pooled | 49.77 | 69.25 | 59.51 |
| pooled_source | 49.04 | 69.06 | 59.05 |
| separate_shared | 49.02 | 68.46 | 58.74 |

주 분석에서 통합 학습의 Macro 오차가 개별 학습보다 0.81분 컸다(짝지은 조건부 95% CI: 0.12–1.54분 증가). 출처 one-hot은 통합 모델의 Macro 오차를 0.46분 줄였지만(보조 비교 CI 0.12–0.80), 개별 학습의 우위를 뒤집지 못했다. HYBRID39의 추가 특징 효과는 네 전략 모두 Macro CI에 0이 포함됐다. 기존 설치 모델은 유지한다.

전체 24개 성능 행과 24개 짝지은 비교, 모든 bootstrap CI를 예측 CSV에서 독립 재계산했고 Workbench 저장 결과와 일치했다. 상세 수치와 전체 범위 진단 그림은 [완료 보고서](../../reports/cmi_mesa_controlled_20261104/REPORT.md), 재검산 근거는 [검증 기록](../../reports/cmi_mesa_controlled_20261104/VERIFICATION.json)에 있다.
