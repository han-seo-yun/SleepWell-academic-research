# SleepWell 세 단계 사용법

기본 메뉴는 **데이터 품질 → 모델 실험·시각화 → RAG 보고서**입니다.
전향 기록, 후향 검증 설계, 교차검증, 재학습, 일반 데이터 도구는 기본 메뉴에서 제거했습니다.
기존 데이터·실험·보고서는 보존합니다.

1. **데이터 품질**에서 파일을 불러오거나 `기존 CMI·MESA 자료`를 선택합니다.
   전체 자료의 행 수, 참여자 수, 결측, 중복, 시간 오류와 열별 상태를 확인합니다.
   필수 열은 `participant_id`, `cutoff`, `sleep_start`, `sleep_end`, `observed_at`이며,
   기존 CMI/MESA의 `subject_id`, `bed`, `wake`도 연결합니다. 원자료를 자동 정리하지 않습니다.
2. **모델 실험·시각화**에서 자료 출처·분할, 참여자 수, 1인당 밤 수와 모델을 고릅니다.
   기본은 Train 자료에서 ID 순 첫 3명과 각 참여자의 처음 30밤입니다.
   `all`은 출처 필터를 풀어 두는 옵션이며 코호트별 균등 추출을 뜻하지 않습니다.
   실제 코호트별 인원수는 실행 결과와 PDF에 기록됩니다.
   분할 열이 없는 파일은 전체 자료가 선택 대상입니다. 실행 범위는 최대 10명·365밤입니다.
   별도 입력 사본으로 실행하며 원본 파일과 기존 Train/Validation/Test 구분은 그대로입니다.
   진행 상태와 중단 버튼은 같은 화면에 있고, 계산 완료 후 MAE·RMSE·오차 방향·허용오차 내 비율·실제값/예측값·오차 분포·참여자별 성능을 탭으로 비교합니다.
   각 모델을 켜거나 끄고 예측 대상·집계 방식을 바꿀 수 있습니다. 모든 그래프는 Python Matplotlib로 실행됩니다.
   ROC-AUC·민감도·분류 정확도는 현재 회귀 모델에 적용되지 않는 이유를 별도 탭에서 설명합니다. [지표 정의와 비교 방법](MODEL_COMPARISON.md)
   이는 탐색 실험이며 새 참여자 검증 또는 독립 외부 검증 성능을 뜻하지 않습니다.
3. **RAG 보고서**에서 결과를 확인하고 `근거 검색 후 PDF 저장`을 누릅니다.
   방금 완료한 실험을 우선 선택합니다. `기준 모델 · gradual_v1 평가`는 별도 출처입니다.
   공식 지침의 로컬 검색과 출처 연결을 사용하며, 성능 수치는 검증된 실행에서만 가져옵니다.
   **키 없이 기본 PDF 저장**은 외부 AI 전송 없이 작동합니다. **AI 연결 설정 → AI 근거 분석·보고서 작성**은 선택적 API/ChatGPT 연결을 사용해 성능·지침 근거·한계를 분석하고 미리보기를 제공합니다. **선택 보고서 PDF 저장**으로 검증된 수치와 Matplotlib 그림을 포함한 PDF를 받습니다. [연결·사용 방법](AI_REPORT_WORKFLOW.md)

그림과 표는 실험 화면에서 각각 저장할 수 있습니다. 화면 언어는 우측 상단에서 바꿉니다.
`Ctrl+S`는 저장, `Ctrl+O`는 프로젝트 열기, `Ctrl+Enter`는 현재 범위의 실험 실행입니다.
실험·근거 처리 실패는 상태에 표시하며, 다른 성공 결과로 바꾸어 보고하지 않습니다.
