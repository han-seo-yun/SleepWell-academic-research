# TRIPOD+AI·PROBAST+AI 근거 검색과 RAG 적용 범위

`prepare_guideline_retrieval(project_path, audit=audit)`는 번들에 포함된 공식
TRIPOD+AI 체크리스트·확장 지침과 PROBAST+AI 도구·해설 PDF 네 개의 SHA-256을
검증한 뒤 프로젝트별 근거 라이브러리에 색인한다. 검색은 각 공식 문서 안으로
제한되며, 보고서에 전달되는 인용에는 원문 해시, 페이지 위치, 검색 ID, 청크
해시가 남는다. 문서마다 인용 발췌는 한 번, 20단어 이하로 제한한다.

현재 구현은 로컬 검색 근거를 결정론적 보고서 템플릿에 연결한다. 외부 API나
생성 모델을 호출하지 않으므로 엄밀한 의미의 생성형 RAG는 아니다. RAG의 원
논문은 검색기가 가져온 비모수 지식과 생성 모델을 함께 사용하는 구성을
설명한다: [Lewis et al., NeurIPS 2020](https://proceedings.neurips.cc/paper/2020/hash/6b493230205f780e1bc26945df7481e5-Abstract.html).

향후 승인된 로컬 생성 모델을 선택 기능으로 붙일 수 있다. 이 경우에도 생성
문장은 인용 청크와 일치하는지 다시 검사하고 사람이 검토해야 한다. 프로젝트
자료를 외부 서비스로 보내는 기능은 이 경로에 포함하지 않는다.

RAG가 담당할 수 있는 범위는 공식 지침의 관련 문단 검색, 보고 항목의 근거
위치 제시, 작성 초안 보조까지다. 다음 항목은 RAG로 충족시킬 수 없다.

- 독립적으로 수집된 외부 데이터 또는 전향 데이터의 생성
- 기존 재사용 holdout 평가를 외부 검증이나 전향 검증으로 변경
- TRIPOD+AI 충족 상태와 PROBAST+AI 편향 위험 판정의 자동 변경
- 연구자 확인이 필요한 윤리, 등록, 데이터 접근권, 이해관계 선언의 추정

감사 스냅샷을 함수에 넘기면 상태별 개수와 전체 판정만 구조화해 반환하며,
그 내용은 검색 색인에 넣지 않는다. 성능 수치와 체크리스트 판정은 검증된
`gradual_v1` 평가 및 감사 스냅샷에서 결정론적으로 복사해야 한다.
