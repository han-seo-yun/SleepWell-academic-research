# 일반 정형 데이터 워크벤치 검증 기록

이 문서는 학술제 전용판을 만들기 전에 수행한 일반 분류·회귀 워크벤치 검증을 보존한다. 최신 학술제 전용판의 최종 검증 상태는 루트의 `VALIDATION.md`를 따른다.

## 자동 검증

2026-11-01, Windows의 프로젝트 전용 `.venv`(Python 3.12.1)에서 확인했다.

- `install.ps1 -NoShortcut`: 고정 버전 19개 패키지 설치 완료. `pip check` 결과 `No broken requirements found`.
- 당시 `.venv\Scripts\python.exe scripts\run_validation.py`: 64개 테스트 통과, 실패 0, 55.222초. 데이터 누수 방지, 그룹·시간 분할, 양성 클래스·임계값, 계산 불가 지표, 타깃 변환 복원, 저장·복원·해시 변조 탐지, 한국어·영어 그림, 비교 변화량, 분류·회귀 통합 흐름을 포함했다.
- Windows `spawn` 자식 프로세스의 완료·결과 저장, 대기 작업 취소, 실행 작업 취소 후 프로세스 종료, 종료 시 강제 정리와 주기적 `poll()`의 비차단 동작을 확인했다.
- `.venv\Scripts\python.exe -m examples.end_to_end --output <새 임시 폴더>`: 종료 코드 0. 분류·회귀에서 기준 실험과 피처 제거 실험을 실제 실행했다.
- 프로젝트 2개와 실험 기록 4개를 재열기 가능한 형식으로 저장했다.
- PNG·PDF·SVG·Excel 결과표를 실제 생성했다.
- `deliverables/examples/`에는 이진 분류·회귀, 다중 분류, MLP와 두 작업 병렬 프로젝트를 실제 학습한 일반 워크벤치 예제가 있다.

설치 검증 중 네트워크 실패가 발생했을 때 이전 스크립트가 다음 단계로 진행하는 결함을 발견했고, 외부 명령의 종료 코드를 검사하도록 수정한 뒤 깨끗한 `.venv` 설치를 다시 통과시켰다.

## 당시 Tk GUI 검증

Tk 위젯을 deiconify하여 900×650과 1440×940 창에서 일곱 페이지를 생성·이동했다. `tk scaling` 1.0/1.5/2.0을 적용해 최소 창 크기, 스크롤 영역, 표시 위젯의 유효 폭을 자동 검사했다. 이는 Tk 내부 기하 검사이며 Windows 디스플레이 설정의 실제 OS 100/150/200% 육안 검증은 아니다.

한국어↔영어 즉시 전환, 초안·피처 선택 유지, 비교 결과 선택·복제·최종 테스트 잠금, PNG/XLSX 내보내기를 확인했다. MLP 실행 중 UI heartbeat, 라이브 학습 그림, 취소 후 자식 프로세스 종료와 `cancelled` 상태를 확인했다.
