# 선택 모델 비교 보고서: 구현·검증 기록

2026-11-05. 기본 화면에서 **모델 실험·시각화 → RAG 보고서 → 근거 검색 후 PDF 저장**으로 출력한다. 비교 화면의 실행별 모델 선택, 예측 대상, 집계 방식, 허용오차를 이어받는다. 생성 버튼을 누른 시점의 선택을 복사하므로 생성 중 화면을 바꿔도 출력 내용은 유지된다.

## 출력 내용

- 선택한 모델만 포함한 MAE·RMSE·평균 편향·허용오차 내 비율과 공통 밤·참여자 수, 제외 건수.
- Python Matplotlib 그래프 7종: MAE, RMSE, 편향, 허용오차 내 비율, 실제값–예측값, 야간 오차 분포, 참여자별 MAE.
- MAE 점추정치의 조건부 순위와 다음 순위와의 차이, RMSE·허용오차 기준과의 일치 또는 절충. 동률과 단일 모델은 별도로 설명한다.
- 공식 지침의 로컬 검색 결과와 문헌 제목·페이지·클릭 가능한 링크. 수치 근거는 동결 실행에서 재계산하고 문헌 검색은 수치를 생성하지 않는다.
- TRIPOD+AI 비교 보고 관련 항목, PROBAST+AI 평가자 검토 영역, 현재 자료로 보완할 분석, 메타데이터 및 연구자 확인, 외부 자료가 필요한 일반화 평가.

문헌 검색과 고정 서식을 사용하는 경로이며 생성형 LLM 및 외부 AI 전송은 사용하지 않는다. 전체 TRIPOD+AI 충족 또는 낮은 PROBAST+AI 편향 위험을 자동 선언하지 않는다. 반복 관측을 독립 표본으로 간주하는 신뢰구간이나 통계적 우월성도 생성하지 않는다. 원시 예측이 없는 과거 실행은 보관된 성능 보고서 경로를 유지한다.

## 검증 결과

앱의 `.venv`에서 관련 15개 테스트 모듈 **84개가 통과**했다. 선택 모델 격리, 화면 설정 고정, 빈 선택 차단, 단일 모델·동률·집계 방식, 수치와 문구 변조 차단, 원 실행 보존, `.swa` 이동 후 재검사, 기존 보고서 호환성과 실제 PDF 출력을 포함한다. 산점도 제목·축 설명·각주의 겹침 여부를 1·3·9개 모델에서 검사한다. `compileall`도 통과했다. 별도 lint/typecheck 설정과 Ruff 설치는 없다.

실제 저장된 CMI Train 결과에서 `cmi.data`, `cmi.hybrid`, `baseline.recent7`을 선택했다. 취침 시각·참여자 동일 가중·±30분 조건의 공통 **52밤·3명**을 사용했다. 세 모델의 MAE는 각각 **62.54분, 66.78분, 67.81분**이다. 이는 설치 모델의 새로운 독립 성능 평가가 아닌 기존 자료의 탐색 비교다.

최종 PDF **11쪽·그래프 7종**을 생성하고 모든 페이지를 100 DPI PNG로 렌더링해 글자·표·축·범례·페이지 배치를 직접 확인했다. 화면과 PDF의 집계 수치가 일치하고 미선택 모델이 제외되는 것을 확인했다. 자동 근거 검사 오류는 0개이며, 통계적 우월성·전문가 판단·검색 문헌의 의미 검토에 관한 남은 경고는 문서에 명시했다.

최종 산출물과 기록은 `../../reports/selected_model_report_20261105/final/`의 PDF, `VERIFICATION.json`, `rendered/`에 있다. 통합 검사 로그는 `../../reports/selected_model_final_tests_20261105.log`다. 기존에 실행 중인 창의 코드 교체나 강제 종료는 하지 않았으며 다음 앱 실행부터 변경 코드가 적용된다.
