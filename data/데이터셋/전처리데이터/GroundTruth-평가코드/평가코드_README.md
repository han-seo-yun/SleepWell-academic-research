# Sleep-EDF Ground Truth & 공통 평가 코드 (소빈)

Sleep-EDF의 PSG 수면단계를 **정답(Ground Truth)** 으로 정리하고,
모든 모델(공식·AI)을 **같은 기준으로 채점**하는 공통 평가 코드입니다.

---

## 1. 폴더/파일 구성

- `Sleep-EDF_GroundTruth/` — 정답 CSV (하위 `SC/` 153개, `ST/` 44개)
- `평가코드.py` — 공통 평가 코드
- `작업보고서_최소빈.pdf` — 작업 내용 보고서 (처리 과정·설계 근거)

---

## 2. 데이터 형식 (★ 예측 낼 때 이 형식 맞춰주세요)

정답·예측 모두 아래 형식의 CSV입니다. **예측도 이 형식으로 내주셔야 채점됩니다.**

| 열 | 설명 |
|----|------|
| `subject_id` | 피험자 (예: SC00, ST01) |
| `night` | 밤 번호 (1 또는 2). 없으면 매칭에서 자동 제외 |
| `epoch_idx` | 녹화 시작부터 몇 번째 30초 epoch인지 (0,1,2…) |
| `stage_label` | **정수 0~4** (0=W, 1=N1, 2=N2, 3=N3, 4=REM) |

- 1행 = 30초 epoch 1개
- 예측 파일 최소 필수 열: `subject_id`, `epoch_idx`, `stage_label`
  (`night` 있으면 매칭에 함께 사용)
- **M(움직임)·unknown 등 0~4 밖의 값은 평가에서 자동 제외됩니다.**
- ※ 정답 파일에는 `onset_sec`(시각)·`stage_name`(단계 이름) 열도 있으나, 이는 참고용이며 **예측에는 넣지 않아도 됩니다.**

## 3. 평가 코드 사용법

1. 라이브러리 설치 (최초 1회)
   ```
   pip install pandas scikit-learn numpy
   ```

2. `평가코드.py` 맨 위 **두 줄만** 본인 경로로 수정
   ```python
   GT_FOLDER   = r"...Sleep-EDF_GroundTruth"   # 정답 폴더 (하위 SC/ST 자동 포함)
   PRED_FOLDER = r"...예측폴더"                 # 예측 CSV 폴더
   ```

3. 실행 (`python 평가코드.py` 또는 Jupyter에 붙여넣기)

### 출력
- Accuracy
- **F1 (macro)** ← 단계 불균형에 공정한 대표 지표
- F1 (weighted), 단계별 F1
- Cohen's Kappa
- Confusion Matrix (행=실제, 열=예측)

---

## 4. 동작 방식 (2단계)

1. **형식 검증** — 필수 열·라벨(0~4) 확인. 어긋나면 무엇이 틀렸는지 알리고 **멈춤**
   (값을 임의로 고치지 않음 → 잘못된 채점 방지)
2. **평가** — 정답·예측을 `(subject_id, night, epoch_idx)` 기준으로 맞춰 지표 계산

> 공식 예측·AI 예측을 각각 이 코드에 넣어 나온 점수를 비교하면,
> "물리 공식 대비 AI 보정이 개선됐는지"를 같은 잣대로 확인할 수 있습니다.

---

## 5. 참고: 설계 결정

- **단계 기준**: R&K 8종(W/R/1/2/3/4/M/?) → AASM 5종으로 통일 (3·4→N3 통합, M·? 제외)
- **subject_id / night 분리**: Sleep-EDF는 한 사람이 2박이라, 밤을 `night` 열로 분리해
  `(subject_id, night, epoch_idx)` 3개로 매칭 (밤이 섞여 충돌하지 않도록)
- **예측 출처와 무관**: 형식만 맞으면 어떤 예측이든 채점하는 범용 채점기

> 정답 데이터의 상세 처리 과정(EDF 읽기 → epoch 전개 → 리매핑 → 제외)은 작업 보고서를 참고하세요.
