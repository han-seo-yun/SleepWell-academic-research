# SleepWell 보조 데이터

수집일: 2026-10-08. 공개 원자료, 코드북, 처리 코드, 연령별 참고표를 보관합니다.
이 폴더의 통계는 **미국 과거 조사 표본의 관측값**이며 한국 성인의 정상치·건강 목표·학생 평균이 아닙니다.
기존 앱의 설정과 학습 모델을 자동 변경하지 않았습니다.

성인 운동·수면 설문은 5,856행이며 운동시간 계산 가능자는 5,846명입니다. 조도 일자료는 69,018행, 시간자료는 1,477,045행입니다. 품질·관측일 기준 적용 후 일별 조도 참고표에는 성인 4,316명이 포함됩니다. 나머지 실제 처리 행 수는 `processed/processing_report.json`에 기록합니다.

걸음수 원본 74,874,095분을 처리했고, 4일 이상 적합 관측이 있는 성인 3,377명의 참고 통계를 생성했습니다. 원본 10개 총 약 646 MB의 체크섬 및 네 참고표 총 798행의 구조 점검을 완료했습니다. 상세 점검 범위와 미검증 항목은 `processed/VALIDATION.md`를 확인하세요.

## 파일 안내

- `raw/`: CDC 공식 XPT/ZIP 및 국내 보고서 원본
- `sources/`: 코드북 HTML/텍스트, 사용 조건, 가중치 안내
- `manifest.json`: CDC 원본 URL, 다운로드 시각, 파일 크기, SHA-256
- `korea_manifest.json`: 국내 보고서 출처와 이용 조건
- `processed/age_activity_sleep_reference.csv`: 연령대·성별 운동/활동/수면 평균·중앙값·사분위수
- `processed/age_steps_reference.csv`: 연령대별 걸음수 (원계수/저강도 제외계수 모두 보존)
- `processed/age_light_activity_reference.csv`: 일별 조도/활동 참고표
- `processed/age_hourly_light_reference.csv`: 시간대별 착용 센서 조도 참고표
- `processed/supplementary_reference.sqlite3`: 위 네 참고표를 SQL로 읽는 DB
- `processed/candidate_age_priors.json`: 앱 초기값 연결을 위한 후보. `auto_apply=false`
- `processed/*.parquet`: 개인 단위 또는 개인·일/시간 단위 분석 중간표
- `scripts/`: 다운로드·재현·간단한 처리 규칙 테스트

## 처리 원칙

### 연령별 운동량

18–29, 30–39, …, 70–79, 80+로 묶습니다. 조사에서 고령 연령을 상한 처리하므로 최고 연령을 정확한 나이로 해석하지 않습니다. 전체 및 조사 성별(남/여) 표를 제공합니다.

운동은 여가 중강도·고강도에 대해 `일주일 운동일수 × 운동하는 날 분 / 7`을 합한 값입니다. 모든 성인을 분모로 하며 운동하지 않는다고 응답한 사람은 0, 거절/모름은 결측입니다. 노동·이동 활동은 별도 변수로 둡니다. 설문 운동과 센서의 활동 분·걸음수를 동일 지표로 취급하지 않습니다.

설문끼리 결합한 표는 `WTINT2YR`를 사용합니다. 관측 수면시간의 저/고 범주 코드(3시간 미만, 14시간 초과)는 정확한 시간으로 치환하지 않고 제외했습니다. 평균에는 자기보고 오차·극단값 영향이 있어 중앙값과 사분위수도 제공합니다.

### 조도

`PAXLXSD`/`PAXLXSH`는 각각 일/시간의 **분별 평균 lux의 합**입니다. 유효 분수로 나눠 평균을 구합니다. 2,500 lux 이상은 상한 처리되어 밝은 야외를 세밀하게 구분할 수 없습니다. MIMS는 움직임 지표이며 걸음수가 아닙니다.

일별 표: 첫/마지막 부분일을 제외한 2~8일, 1,440분 기록, 유효 ≥1,380분, 수면+각성 착용 ≥1,200분인 날을 선택하고 4일 이상인 사람의 평균을 냅니다. 이 표의 lux에는 일부 비착용 값이 남을 수 있습니다.

시간별 표: 유효 ≥50분, 비착용/불명 분수 0인 시간만 사용합니다. 측정 시작시각과 시작 표본번호/80Hz로 시계 시간을 복원합니다. 동일 사람·동일 시각에 ≥200 유효 분이 있을 때 분수 가중 평균을 냅니다. 엄격한 조건으로 일부 시간대가 선택적으로 빠질 수 있습니다.

조도는 손목 장치가 받은 빛입니다. 눈에 도달한 빛, 스펙트럼, melanopic EDI와 다릅니다. 수면/각성은 장치 알고리즘의 추정값이며 PSG 정답이 아닙니다.

### 걸음수

2005–2006 AM-7164 허리 센서는 잠잘 때 제거하는 프로토콜입니다. 기기 신뢰·교정 플래그가 모두 정상인 성인만 사용합니다. 연속 60분 이상 0 활동량을 비착용으로 간주하는 **단순 탐색 규칙**을 사용합니다. NCI의 최대 2분 저강도 허용 규칙과 동일하지 않습니다.

전체 1,440행인 날 중 품질 적합 착용 ≥600분인 날을 남기고, 4일 이상인 사람의 평균을 냅니다. 분별 걸음 0~300, 강도 0~32766만 유지하며 그 외는 유효 착용 분에서 제외합니다. 500 counts/min 미만 걸음을 제외한 값과 원계수 합을 모두 보관합니다. 이 기기 출력과 Apple/Samsung 걸음수의 직접 일치는 검증하지 않았습니다.

### 가중치와 불확실성

센서 표는 각 사람의 유효일 평균을 먼저 구하고 `WTMEC2YR`로 집계합니다. 반복 측정 행을 독립 사용자로 세지 않습니다. 결측/착용 불충분에 대한 추가 무응답 보정 및 복합표본 설계 신뢰구간은 미계산입니다. Kish effective n은 가중치 불균등 요약이며 독립표본 수나 설계 자유도가 아닙니다. 따라서 결과는 **탐색적 초기값 후보**입니다.

서로 다른 조사 주기를 개인 단위로 연결하지 않습니다. 동일 주기 내부의 공개 SEQN 결합만 사용합니다. 본인 Samsung 기록과 NHANES 사람을 매칭하지 않습니다.

## 성능 개선에 어떻게 쓸 것인가

1. 가입 시 활동량을 모르는 성인에게 연령별 분포를 출처와 함께 참고값으로 보여줍니다. 본인 입력과 최근 측정이 있으면 그것을 우선합니다.
2. 초기값 후보의 영향력은 신규 사용자 전체를 분리한 검증으로 정합니다. 연령 평균을 강하게 적용하면 개인차·국가 차이 때문에 오히려 나빠질 수 있습니다.
3. 조도는 당장 연령 평균을 개인 입력에 채우지 않습니다. 저녁/아침 시간대의 실제 노출 측정 또는 구조화된 야외·실내 기록을 먼저 수집합니다.
4. 기존 추천, 연령 참고값 추가, 실제 조도 추가를 비교하는 제거 실험을 합니다. 수면 시각 오차뿐 아니라 다음날 개운함·피로, 일정 준수율을 평가합니다.
5. 추천을 따랐을 때 수면이 개선되는지는 이 관찰자료만으로 입증되지 않습니다. 전향적 개인 기록과 비교 설계가 필요합니다.

## 국내 데이터와 이용 조건

국민생활체육조사 공식 보고서는 공공누리 제4유형(출처표시·상업적이용금지·변경금지)으로 제공됩니다. 원본 참고용으로 보관하고 학습/자동 초기값에 넣지 않았습니다. 한국인 운동량 사전분포에는 동일 조사의 이용 가능한 마이크로데이터, 국민건강영양조사 신체활동 자료 등을 후속 후보로 검토할 수 있습니다. 걷기 실천율을 하루 걸음수로 변환하면 안 됩니다.

NHANES는 공개 통계 분석용 자료입니다. 재식별, 식별 가능한 다른 개인자료와 연결하는 용도로 사용하지 않습니다. 자세한 조건과 인용은 내려받은 안내 및 아래 공식 링크를 따릅니다.

## 재현

```bash
/opt/homebrew/bin/python3.11 scripts/download_sources.py
/opt/homebrew/bin/python3.11 scripts/download_korean_report.py
/opt/homebrew/bin/python3.11 scripts/build_reference_tables.py --part all
/opt/homebrew/bin/python3.11 scripts/package_references.py
/opt/homebrew/bin/python3.11 scripts/test_processing.py
/opt/homebrew/bin/python3.11 scripts/verify_package.py
```

필요 모듈: requests, beautifulsoup4, pandas, numpy, pyarrow. 원본 파일이 이미 있으면 다운로드 스크립트는 재다운로드하지 않습니다. 걸음 ZIP은 압축을 통째로 해제하지 않고 읽어 디스크 사용을 줄입니다.
